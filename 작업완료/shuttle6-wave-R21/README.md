# Shuttle6 C R21 — 얇아진 외관·앞쪽 갓·반원 뒤끝

바깥통 일반 벽의 외면을 최대1.2mm 안쪽으로 줄였습니다. 실제 단면 표본은 약4.0~4.2mm에서2.9~3.2mm입니다. 레일·잠금부·물결 접합부·맨 안쪽 반원 받침 자리는 두께를 유지했습니다. 본 수납부 내경64mm와 내관의 둥근 안쪽 형상은 유지합니다.

기존 갓 형상을 뚜껑 바로 뒤로 옮겼고, 반대쪽 끝은 위가 열린5.8mm 두께의 반원으로 바꿨습니다. 외관 맨 안쪽 반원 홈에4.1mm 들어가 자리 잡습니다. R20은 갓이 뒤에 남아 있던 버전으로 철회했습니다.

R20에서 아래통·위통·내관3파트를 교체합니다. 뚜껑·클립·양옆 멈춤블록·시험편2개, 나머지6파트는 공칭 정점과 면 배열이 동일합니다. 뒤끝 중앙에는 얇은 지붕이나 콘이 없으며, 레일 걸림용 원래 양옆 포스트만 위로 남습니다.

## 조립·동작 검사

- 기존 갓의 실제 단면과 옮긴 단면 비교:5곳 최대 오차0.0071mm. 게이지 코르크와 최소 표본 여유1.94mm.
- 뒤쪽 열린 중앙4곳 위로 광선 검사: 막는 면0개. 뒤벽 두께 실측5.800mm.
- 225mm 길이·Ø64mm·포갬 간격28mm의6개 치수 게이지: 내관 간섭0mm³. 뒤로0/2/4mm 이동해도 간섭0.
- 마지막 깃털 원판: 측방±0.25mm·축방향0/2/4mm 표본에서 간섭0.
- 새 반원 받침과 원형 뒤끝의 실제 솔리드 인출0~12mm9개 표본: 간섭0.
- 딸깍 위치는 닫힘 포함0/36/72/108/144/180mm. 이후225mm에서 별도 좌우 멈춤블록에 걸립니다.225.1mm부터 의도적 걸림 부피가 생깁니다.
- 단계 사이에는 기존 돌기와 외관의 의도된 강체 겹침이 남습니다(이번 추가 표본 최대1.128mm³). 원래 채널로 돌기를 눌렀다고 가정한 경로 대체모델에서는 몸통 간섭0입니다. 이는 실제 변형률·힘·수명 검증이 아닙니다. 원본 강체 겹침 수치를 `qc/assembly.json`에 함께 보존했습니다.
- 클립0~90° 표본: 몸통·뚜껑 간섭0. 닫힌 클립을 당기면0.4mm부터 몸통에 걸립니다.
- 양옆 멈춤면 합계56.79mm², 안쪽 표본 틈0.200mm. 가정30N 정적 인출의 평균 면압0.528MPa, 한쪽만 받으면1.057MPa. 충격·적층·피로를 반영한 파손 하중이 아닙니다.
- 첫 콕을 위로0/10/30/60/80mm 들어 올리는 경로에서 내관·뚜껑 간섭0. 인접 깃털과 손 접근은 미검증입니다.
- 고리 구멍 단면5.000×5.000mm. 기존 몸통·뚜껑으로 눕혔을 때 고리 주변은 지지면 위61.18mm 이상. 금속 링·실물 구름 안정성은 미검증.

GIF는 실제 최종 메시와 치수 게이지를 사용하는 동작 시각화입니다. 실제 브랜드6개 실측·깃털 마찰·인출력·반복 내구성 시험을 대신하지 않습니다.
