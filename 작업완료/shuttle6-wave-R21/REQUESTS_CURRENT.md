# 현재 요구사항 — R21

- 기존 갓 모양을 뚜껑 바로 뒤쪽으로 옮긴다. 새 대체 콘으로 바꾸지 않는다.
- 내관 뒤끝은 배처럼 열린 반원형이며, 얇은 막이 아닌5.8mm 두께의 반원 마감이다. 위쪽에는 레일 걸림용 양옆 포스트만 남긴다.
- 외관 맨 안쪽 반원 홈에 약4mm 들어가 자리 잡게 한다. 입구0.35mm·안쪽0.2mm 여유로 설계한다.
- 이탈 방지는 기존 양옆 레일 스토퍼가 담당한다.
- 바깥통 일반 벽을 최대1.2mm 얇게 하되 레일·잠금·접합·반원 받침은 유지한다.
- 본 수납부64mm,6개,코르크 앞쪽,Ø5 옆면 고리,물결 접합,별도 뚜껑을 유지한다.
- R20은 콘 위치 미수정본으로 철회. R21은 디지털 형상·조립·출력 메시·3MF 검증을 완료했다. 실물 출력 시험은 미실시다.
