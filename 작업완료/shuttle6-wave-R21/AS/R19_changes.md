# R19 Ø5 열쇠고리 AS 기록

위치: 몸통 위통 입구, 클립 반대편. 몸통 좌표에서 구멍 중심X=0,Y=-47mm, 고리Z=239~243mm. upper 로컬 좌표에서는Z=117.5~121.5mm입니다.

고리는 위통에 일체형으로 붙이며 별도 작은 부품을 끼우지 않습니다. 외측 원반R6.5에서 Ø5 원을 관통시키고 폭16mm의 뿌리를 둥근 윤곽으로 연결했습니다. 두께4mm, 구멍 둘레 살 공칭4mm, 뿌리 모서리R1mm입니다. 내경이나 슬라이드 레일을 깎지 않았습니다.

## 출력과 검증

위통은 입구를 바닥으로 뒤집어 출력합니다. 고리도 같은 바닥면Z=0에서 시작하고4mm 높이까지 세워 쌓이므로 Ø5 구멍에 천장 브리지가 없습니다. 기존 위통의 레일 천장 서포트는 유지합니다.

공칭 메시 단면의 구멍은5×5mm이며 실제 출력 후 크기는 재료 수축과 기계 보정에 따라 달라집니다. Ø5 게이지와 메시 간섭0, 닫힌 뚜껑 간섭0, 고리 끝면 출력Z=0을 자동 확인했습니다. 나머지8파트 공칭 정점과 면 배열이 R18과 같다는 것도 확인했습니다.

뿌리 휨은 tools/beam.py의 직사각 캔틸레버 모델로 참고 계산했습니다. 가정L14.5,b12,h4mm,E3300MPa,가정 횡하중20N에서 응력9.0625MPa·처짐0.0962mm입니다. 실제 고리의 구멍 응력 집중, 곡면 뿌리, 적층 결합과 충격·피로를 반영하지 않으므로 허용 하중이나 실제 파손 하중으로 사용하지 않습니다. 실물 열쇠고리 결합 및 당김 시험은 미실시입니다.

## 재현

scripts/build.py는 AS/reference_R18_parts.pkl을 입력으로 위통만 변경합니다. AS/reference_R18_build.py는 R18 원본 구조 출처입니다. 전체 실행 순서는 build.py → print_qc.py → assembly.py → keyring_checks.py → preview.py → export_delivery.py 입니다. preview.py에서 keyring_preview.py를 함께 실행합니다. 그 밖의 R18 걸림부 기록은 AS/R18_changes.md와AS/README_R18.md에 보존했습니다.

교체 시 위통과 고리를 함께 재출력합니다. 고리 뿌리의 백화·갈라짐·층 분리가 보이면 교체합니다. 작은 딸깍 유지 돌기를 열쇠고리 하중을 받는 부위로 변경하지 않았습니다.
