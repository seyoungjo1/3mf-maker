# Shuttle6 C — R18 양옆 서랍 스토퍼 보강

Ø64 수납공간과 기존 물결 외관을 유지하며 뒤컵의 양옆 걸림턱과 입구 스토퍼를 보강한 6개용 슬라이드 통입니다. 몸통은 세워 출력하는 두 조각, 내관은 작은 외부 평면을 바닥으로 눕혀 출력하며 뚜껑은 별도입니다.

## 파일

- 출력 프로젝트: `models/Shuttle6_C_R18_side_stop225_reversed_clip_bambu.3mf`
- 일반 3MF: `models/plates/P01.3mf`~`P07.3mf`. 색 번호는 전 플레이트 공통으로 몸통1·내관2·클립3입니다.
- 출력 방향 STL: `models/*_print.stl`
- 전체 작동: `preview/turntable.gif`
- 양옆 걸림부 단면: `preview_stops/turntable.gif` — 파란색은 관찰용이며 출력 파일의 스토퍼는 몸통색입니다.
- 클립: `preview_lock/turntable.gif`; 실제 플레이트 배치: `preview_plates/turntable.gif`
- 각 렌더 폴더에 기본·상부·측면·밑면·정면 PNG가 있습니다.
- 조사 출처와 판단: `AS/drawer_stop_research.md`; 보강 상세와 AS: `AS/R18_changes.md`

## 변경과 측정

- 뒤컵의 좌우 고정 어깨를 폭넓은 뿌리와 연결하고, 옆면 뿌리는 둥글게 처리했습니다. 끝에서 힘을 받는 면은 경사면 대신 인출 방향에 수직입니다.
- 걸림면 끝 높이6→12mm, 방사방향 맞물림 폭1.4→2.0mm. 뿌리는 높이18mm까지 넓어집니다.
- 실제 메시의 양쪽 유효 접촉 면적은 약57.17mm²로 R17의16.80mm² 대비3.40배입니다. 강도나 수명이3.40배라는 뜻은 아닙니다.
- 스토퍼는 몸통 포켓의 축방향 벽에 받쳐집니다. 작은 돌기는 외측 장착 유지용이며 끝 인출 하중을 맡기지 않습니다. 표면을 따르는 바깥 머리는1.2→1.8mm로 두껍게 했습니다.
- 레일 홈은 어깨 윤곽을 따라 잘라 넓은 직사각 홈이 몸통 벽을 얇게 만들지 않도록 했습니다. 7개 단면·단면당95곳의 벽 측정 최소값은1.398mm입니다. 전 영역 최소 두께 보증은 아닙니다.
- 본 수납부 내경64mm, 내관 벽2.6mm·바닥2.8mm, 작은 외부 받침 폭16mm를 유지합니다. 뒤컵 원형 가이드 길이14.8mm와 얕은 내부 곡면도 유지합니다.
- 정상 인출 검사0~225mm에서 몸통·스토퍼 간섭0mm³.225.1mm에서 양옆 스토퍼에 의도적으로 걸립니다. 포켓 유격에 따라 실물 끝 위치는 약225mm입니다.
- 뒤컵과 스토퍼 안쪽 평면의 표본 최소 간격0.200mm, 몸통 두 조각 간섭0mm³, 클립0~90° 검사 간섭0mm³입니다.
- 셔틀콕6개 치수 게이지와 내관 간섭0mm³입니다. 게이지는 길이225mm·포갬 간격28mm를 가정한 치수 형상이며 실제 브랜드6개를 측정한 결과가 아닙니다.

P1S,0.4mm 노즐,PLA,0.2mm 층,벽4줄,15% gyroid,외측 브림10mm 설정입니다. 실제 사용자 Bambu Studio 템플릿에서 설정을 가져왔습니다.

## 조립과 하드웨어

1. 몸통 두 조각은 기존 내부 직선 끼움과 외부 물결 형상을 맞춰 접착합니다. 새로 반영된 넓은 좌우 통로에는 접착제를 남기지 않습니다.
2. 별도 뚜껑과 내관의 기존30mm 사각 키 결합을 맞춥니다. 내관을 외관에 넣은 다음 양옆 스토퍼를 바깥에서 장착합니다. 좌우 스토퍼가 완전히 안착됐는지 확인합니다.
3. 클립은 뚜껑에 축을 두고 몸통 쪽에 걸립니다. **M3×20mm 볼트2개, 일반 M3 너트2개, 금속 스페이서 외경6×내경3.2×길이6.8mm2개**를 사용합니다. 축 구멍은Ø3.4입니다. 볼트는 고정 스페이서를 조이고 움직이는 클립 링을 직접 압착하지 않습니다.
4. 조립 후 천천히 전 구간을 움직여 좌우가 함께 걸리는지 확인합니다. 스토퍼 삽입력, 딸깍 힘과 반복 수명은 실물 미검증입니다.
5. 선택 사항: 평평한 정지면에2×12×0.8mm 실리콘/TPU 패드를 한쪽씩 부착할 수 있습니다. 첫 접촉 위치는 약0.8mm 앞당겨지고 압축 후 단단한 턱이 받습니다. 패드는 기본3MF에 포함하지 않았고, 작은 별도 출력 부품을 추가하지 않았습니다. 패드가 인출 방지를 대신하지 않습니다.
