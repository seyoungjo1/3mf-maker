# 재현

전체 GitHub 프로젝트 폴더의scripts·pipeline설정으로 생성할 수 있습니다. AS의 동결 도구ZIP을 작업 루트에 풀면 검사·렌더·Bambu 템플릿과 참고그림이 복구됩니다. requirements에embreex4.4.0.post1을 포함합니다.

출력자료 ZIP만 있을 경우 작업 루트 아래작업중/shuttle6-wave-R15를 만들고, AS/source를 그 폴더의scripts로, AS/configs의README와JSON을 프로젝트 루트로 복사하세요. AS/reference_R14_dimensions.json을 프로젝트의AS에 보관하고models·qc·figures·drawings 폴더를 생성하세요. R14 기하 파일은 필요 없으며 메타데이터 시드만 사용합니다.

작업 루트에서 `python tools/mm.py make 작업중/shuttle6-wave-R15/pipeline_review.json`, 이후pipeline_final.json으로 생성합니다. 별도의venv를 사용하세요. 실물의 밀착·딸깍 힘·깃털 손상 방지·수명은 시험편과 실제 셔틀콕으로 확인해야 합니다.
