# Shuttle6 C R15

기존 둥근 C형 외관을 복원했습니다. 내관 안쪽은Ø64 원형을 유지하고, 맨 아래 바깥에만 좁은 접시 굽을 추가합니다.

|항목|치수|
|---|---|
|외관|폭78.2mm·옆면R100·모서리R30 유지|
|내관 기본 벽|2.6mm|
|바닥 굽|전체폭16mm·평면폭15mm·중앙 바닥총두께2.8mm|
|슬라이드 간극|편측0.3mm|
|원형 뒤가이드|외경69.2mm·길이27.8mm|
|뒤가이드 결합|겹침10mm·편측접착간극0.2mm|
|딸깍|양옆6곳·피치36mm·통과간섭0.2mm·안착여유0.2mm|
|몸통 이음부|안쪽 직선 끼움 유지·바깥 반원 물결 숫형/암형 맞물림·봉우리 평면4mm·축방향 여유0.1mm|

6개 중첩 길이225mm를 가정하며 브랜드별 실측 확인이 필요합니다. 원형 뒤가이드는 내관의 여러 방향 흔들림을 억제하기 위한 구조입니다. 실제 깃털 파손 방지·딸깍 힘·마모 수명은 검증 전입니다.

몸통은2분할, 내관은눕힘, 앞뚜껑과뒤컵은별도 출력입니다. 부분 서포트를 사용합니다. 상부 몸통은 입구 쪽 평면을 베드로 향하게 뒤집어 놓았습니다.

AS/source와 동결 도구 ZIP을 포함합니다. 재현: `python tools/mm.py make 작업완료/shuttle6-wave-R15/pipeline_review.json`, 이후 `pipeline_final.json`.
