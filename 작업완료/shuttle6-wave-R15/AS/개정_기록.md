# Shuttle6 R15

사용자 수정: 기존 C 외관 유지, 접시처럼 바닥만 좁게 평탄화, 일부 서포트 허용, 내관 뒤끝은 원형, 몸통 연결부는 물결무늬로 감추기, 딸깍감 강화.

내부 반경32mm는 유지. 바깥 굽만 전체폭16mm, 바닥Y−34.8mm로 추가. 측면을 각지게 넓히지 않음. 외관 R100/R30과78.2mm 치수 유지. 내측 대응 홈만 수정. 원형 뒤컵은 외경69.2mm·길이27.8mm·겹침10mm·편측접착간극0.2mm이며 따로 닫힌 끝을 아래로 출력. 좁은 내관은 곡면 바깥·돌기·앞 키에 국부 서포트 사용. 뒤컵은 별도 세움으로 안쪽 곡면의 서포트를 줄임.

몸통 민자띠를 없애고 무늬 위상을 이어서 생성. 기존 네 번째 반원 무늬를 따라 아래통 바깥 숫돌기와 위통 바깥 암홈을 실제로 맞물리게 절단. 봉우리는4mm 평면으로 작게 잘랐고 이 면도 기존 홈 폭 안에 들어감. 안쪽은 원통형 접착 끼움과45° 정렬 키를 유지. 직선 이음선에 물결 그림만 더한 구조가 아님. 상부 몸통은 평평한 입구가 베드를 향하게 뒤집어 출력. 실제 접착 오차는 가려지지 않을 수 있음.

딸깍 돌기는 넓은 솔리드 위에 양옆6곳. 통과 간섭을0.1→0.2mm로 증가, 홈 안착 여유0.2와 기본슬라이드간극0.3 유지. 힘 증가량·마모·깃털 파손 방지 성능은 실물 미검증. 셸 변형을 외팔보식으로 계산하지 않음.

기하연산으로 생긴 합계0.0001mm³ 미만 영부피 잔편만 제거하고 주 몸체가 단일 솔리드인지 재검사.
