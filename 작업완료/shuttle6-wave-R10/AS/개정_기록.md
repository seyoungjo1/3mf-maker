# R10 AS 반영 기록

2026-10-21 사용자 지정 수납 공칭64mm로 축소. 몸통 폭74.6/뚜껑78.6, 몸통 내경68.6/내관 외경68. 바닥 평면 약23mm, 바닥2mm, 긴 내관 눕힘·대각선 출력과 별도 끼움뚜껑 적용. 뚜껑 내부 짧은 결합턱2개는 조립을 고정하는 용도이며, 기존 외관 잠금용 긴 클립은 제거했다. 사용자 단면 스케치(대화 이미지, 내관이 안쪽·외관이 바깥쪽)에 따라 내관 바깥 둥근 돌기2개와 외관 안쪽 홈으로 당김 딸깍을 구현한다. 돌기는 내경으로 침범하지 않도록 안쪽을 잘랐다.

깃털은 강체 플라스틱이 아니며 반원 내관의 위가 열려 있다. 강체Ø68 단순비교로 수납 불가를 단정한 이전 설명은 정정했다.64mm 치수 게이지는 제조 형상 검증이며 실제 깃털 변형·복원·수납 실험이 아니다. 딸깍 통과 강체 교집합은 의도된 탄성 겹침으로 기록하며, 운동학적으로 돌기만 압축한 통과 메시는 실제 재료 해석이나 힘 보증이 아니다.

R9는 보존한다. 테슬라·주차판 파일과 공용 도구는 수정하지 않는다. 재현 도구는 AS ZIP에 프로젝트 내부로만 보관한다.
