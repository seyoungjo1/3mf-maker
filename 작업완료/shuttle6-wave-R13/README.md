# Shuttle6 C R13

사용자 스케치처럼 길이 방향 양옆6곳의 낮은 둥근 돌기와 대응 홈. 외관 내부 아래 한쪽 평면으로 회전 안내. 내관 벽2.6mm·수납 공칭64mm 유지. 얇은 걸쇠/절개 혀 추가 없음.

## 출력·검증 범위
P1S0.4·PLA·0.2층·EFC0.15 선반영·브림10mm. 몸통만 세워2조각, 내관은 눕힘, 뚜껑 별도. 내관 및 시험편 하부 곡면·돌기 아래 트리서포트.6개 적층225mm는 기존 가정이며 브랜드 실측 아님.

딸깍 구조는 기존2.6mm 열린 내관 벽의 미세한 탄성을 사용. 별도의 얇은 암이나 절개를 추가하지 않음. 실물 인출력·소리·마모·반복 수명은 미측정.6곳이 함께 걸리므로 인출 위치별 저항은 일정하지 않음. 시험편은 한 쌍의 국부 끼움 확인용이고6쌍 전체 힘을 증명하지 않음. 압축 표시 형상은 운동학 간섭 검사용이며 재료 해석 아님.

외관 접착 소켓 구간은 평면이 일시적으로 비워지고, 소켓 뒤에4mm 안내 경사로 다시 이어짐. ‘끊김 없는 전장 평면’으로 주장하지 않음.
