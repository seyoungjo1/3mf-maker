# Shuttle6 C — R20 코르크 앞쪽·고리 사선 옆면

셔틀콕의 코르크 머리를 뚜껑 쪽으로 향하게 바꾸고, 깃털이 향하는 뒤컵 안쪽에 축 방향2mm 여유를 확보했습니다. 바닥으로 돌출되던 Ø5 열쇠고리 고리는 제거하고 사선 위쪽 옆면으로 옮겼습니다. 기존 R19에서 **위통과 내관**을 수정했습니다. 나머지7파트의 공칭 정점과 면 배열은 R18/R19와 같습니다.

## 파일과 동작

- Bambu 프로젝트: `models/Shuttle6_C_R20_cork_front_side_eyelet_bambu.3mf`
- 일반3MF: `models/plates/P01.3mf`~`P07.3mf`; 출력 방향STL: `models/*_print.stl`
- 6단계 인출과 첫 콕 꺼내기: `preview_six_steps/opening_six_steps.gif`
- 전체 회전/열림: `preview/turntable.gif`
- 고리 상세: `preview_keyring/turntable.gif`; 양옆 스토퍼: `preview_stops/turntable.gif`; 클립: `preview_lock/turntable.gif`; 출력 배치: `preview_plates/turntable.gif`
- 각 기본 렌더 폴더에 기본·상부·측면·밑면·정면PNG가 있습니다.
- 최신 치수·변경 근거: `AS/R20_changes.md`, `AS/keyring_parameters.json`

6개 걸림 위치는 닫힘 포함0/36/72/108/144/180mm이며, 이후225mm에서 별도의 양옆 이탈 방지턱이 인출을 막습니다. GIF 끝에서는 앞쪽 첫 콕을 코르크 쪽에서 위로 들어 올립니다. 셔틀콕은 치수 게이지이며 실제 깃털·마찰·변형을 재현한 물리 시뮬레이션은 아닙니다.

역방향 게이지는 기존 길이225mm·포갬 간격28mm·지름64mm 가정을 그대로 사용합니다. 실제 브랜드6개 측정값이 아닙니다. 첫 콕 경로 검사는 내관·뚜껑만 대상으로 하며 깃털끼리의 마찰과 실제 인출력은 검증하지 않았습니다.

## 출력과 조립

P1S,0.4mm 노즐,PLA,0.2mm 층,벽4줄,15% gyroid,외측 브림10mm 설정입니다. 실제 사용자 Bambu Studio 템플릿을 사용했습니다. 코끼리발0.15mm 선반영 메시이므로 같은 프로파일의 코끼리발 보정0.15mm를 유지합니다.

몸통 두 조각의 내부 직선 끼움·외부 물결 음양 접합과 접착, 내관-뚜껑30mm 사각 키, 내관 삽입 후 바깥에서 좌우 스토퍼를 장착하는 순서는 유지합니다. 클립은 뚜껑에 축을 두고 몸통에 걸립니다. **M3×20mm 볼트2개·일반M3 너트2개·금속 스페이서 외경6×내경3.2×길이6.8mm2개**를 사용합니다. 축 구멍은Ø3.4mm이며 볼트가 움직이는 링을 직접 압착하지 않게 스페이서를 고정합니다.

물결 외관과Ø64 내경,6개 보관,작은 외부 평면,강화 양옆 스토퍼는 유지됩니다. 양쪽 유효 걸림면은 약56.79mm², 뒤컵과 스토퍼 안쪽 평면의 표본 간격은0.200mm입니다. 작은 딸깍 돌기는 장착 유지용이며 끝 인출 하중은 스토퍼와 몸통 포켓 벽으로 전달합니다. 이전 R18/R19 보강 연구 기록은AS에 보존했습니다.
