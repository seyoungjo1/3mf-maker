# Shuttle6 C R14 출력·조립

내경64mm 원형 반원 수납면을 유지하고, 외부에만 평받침을 더했습니다. 내관 기본 벽2.6mm, 중앙 바닥3.2mm입니다.

1. 먼저 레일 암수 시험편을 출력해 밀착·6단 딸깍 힘을 확인하세요. 공칭 레일 간극은 면 법선 방향0.3mm, 돌기 통과 간섭0.1mm, 안착 홈 여유0.2mm입니다. 재료·유량에 따라 체감이 달라집니다. 무리하게 밀지 마세요.
2. 몸통 두 조각은 각각 세워 출력하고22mm 겹침 키를 맞춰 접착합니다. 접착제가 내측 레일로 흘러들지 않게 하세요. 완전 경화 후 내관을 넣습니다.
3. 내관은 추가된 평받침을 아래로 눕혀 대각 배치합니다. 긴 받침과 레일 돌기는 서포트 불필요 판정을 받았습니다. 앞쪽 사각 뚜껑 연결키 아래85.4mm²에는 국부 서포트가 필요하며 제거 후 뚜껑 안에 가려집니다. 전체 무서포트 모델은 아닙니다.
4. 뚜껑은 별도 출력하고 반원+받침 결합부 및30mm 사각 키를 맞춰 끼웁니다. 둥근 수납면 안에 재료를 메우지 않았습니다.
5. PLA,0.4mm 노즐,0.2mm 레이어,벽4줄,15% gyroid,brim10mm가 기준입니다. 제공 Bambu3MF의 속도는 보수적으로 설정했습니다. 출력 전 슬라이서 미리보기와 프린터·재료 설정을 확인하세요. 실제 G-code 출력 검증은 하지 않았습니다.

수납 길이225mm의6개 중첩 가정이며 브랜드별 실측 확인이 필요합니다. 실제 딸깍 힘·마모 수명·접착 강도는 출력 시험 전입니다. 얇은 외팔보 클립을 레일의 넓은 저상 돌기로 바꿨지만 강도 보증은 아닙니다.
