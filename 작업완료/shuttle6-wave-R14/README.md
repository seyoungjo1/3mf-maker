## 검증 범위
Bambu P1S0.4·PLA·층0.2·EFC0.15 선반영. 긴 내관은 외부 받침 바닥으로 눕혀 대각선 출력, 앞 뚜껑 별도, 몸통만 길이 중간2분할 세움. 긴 받침·레일은 서포트 불필요 판정입니다. 앞쪽 뚜껑 사각 연결키 아래85.4mm²에만 국부 서포트가 남으며 전체 무서포트 모델은 아닙니다.

딸깍 강도·소리·반복 마모·접착 강도는 실물 시험 전입니다. 레일의 압축 표현은 운동학 간섭 확인용이고 재료 해석이 아닙니다. 새 레일은 튼튼한 솔리드이며 바깥 쉘의 작은 변형이 필요합니다. 시험편의 국부 끼움이 여섯 쌍 전체 인출력을 증명하지 않습니다.
