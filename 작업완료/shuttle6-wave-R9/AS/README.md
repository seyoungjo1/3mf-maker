## 다음 크기 AS에서 유지할 조건

현 기준 닫힘 86×86×253mm, 몸통 폭82·길이243, 받침 출력249.8mm입니다. 6개 수납, 몸통만 가로2분할, 일체형 받침/뚜껑, 누름 해제 잠금, 콘 입구45도→즉시 곡률→끝30도·최종4mm는 유지 요구입니다. 3MF 전체 배율 축소는 셔틀콕 공간·끼움 간격·걸쇠 두께까지 줄이므로 사용하지 않습니다.

현재 수납 검사는 가정 외피(깃털Ø68, 코르크Ø28, 총길이85, 적층피치28, 6개225mm)+1.5mm 여유에 대한 것입니다. 이후 크기 AS에서는 실제 사용하는 셔틀콕의 최대 깃털지름·6개 적층 길이와 줄일 방향(폭/길이)을 확인해 필요한 여유부터 다시 결정합니다. 지금은 측정값이나 목표 축소 치수가 제공되지 않았으므로 목표값은 미정입니다.

폭은 외장벽·음각 깊이·접착 소켓·Ø76 슬라이드 통로를 함께 검토하고, 길이는 끝 곡면과 마지막 셔틀콕 여유를 다시 검증합니다. 접착 반경 틈0.30mm와 스프링30.5×3×8·누름1.5mm는 별도로 관리합니다. 수정은 R10 등 새 작업 폴더에서 진행하고 이 R9을 덮어쓰지 않습니다. 수정 후 QC·1.5mm 여유 외피 교집합·인출 전 구간·잠금·브리지·EFC·5뷰/GIF·3MF 검증을 새 형상으로 다시 수행합니다.

## 기준 검증 범위

R9 자동검사 ok=true, 조립/가정 수납 교집합0, 끝 현30.03944도·개구4mm, 검출 최대 브리지4.4mm입니다. 받침 한쪽 돌출 누적19.5mm² 중 기존 잠금부 약15·콘 국부 약4.5입니다. 실제 슬라이싱·출력·브랜드별 실물 수납·반복 내구는 확인 전입니다. Bambu 원본은 구조·설정·형상 왕복 검증, strict0은 표준 플레이트 및 원본에서 만든 형상 검사용 사본 기준입니다.

## 재현

저장소 루트에서 의존성을 설치하고 `MM_RENDER_BACKEND=software python tools/mm.py make 작업완료/shuttle6-wave-R9/pipeline_final.json`을 실행합니다. 기존 결과를 보존하려면 먼저 이 폴더를 새 작업 폴더에 복사하고 그 복사본의 config를 지정합니다. 기본 템플릿과 참고 이미지는 저장소 sample/을 사용합니다. 사용자별 절대 경로를 요구하는 포장 스크립트는 보관 폴더 안의 자가검사 기록을 사용하도록 갱신합니다.

공용 도구와 테슬라·주차판 파일은 이번 업로드에서 변경하지 않았습니다. R9 당시 도구·템플릿은 `AS/R9_재현도구_원본.zip`에 별도 보관했습니다(AS 문서에서는 `R9_재현도구_원본.zip`). 재현 시 원본 저장소를 직접 바꾸지 말고 임시 저장소에 이 ZIP을 풀고 이 프로젝트를 작업완료/shuttle6-wave-R9에 복사한 후 해당 tools/mm.py를 사용합니다.
