# Shuttle6 C R23 — 뚜껑 원형 홈·두꺼운 앞콘 끼움부

뚜껑의 기존 반원 홈을 전체 원형으로 확장했습니다. 앞콘의 원형 뿌리가 뚜껑 안으로3.8mm 들어가도록 연결해 윗부분에 얇은 끝판만 남는 구조를 수정했습니다. 뒤끝은 기존5.8mm 반원이며, 얇아진 외관·64mm 수납부·6개·레일·잠금은 유지합니다.

**R22에서 내관과 뚜껑2개를 함께 교체합니다.** 나머지7파트는 공칭 정점과 면 배열이 R22와 동일함을 확인했습니다.

원형 홈은 기존 아래쪽의 좁은 받침 자리와 합쳐지므로 그 작은 받침 윤곽은 남습니다. 사각 키는 원형 홈 바닥보다 더 깊은 곳에 남겨 방향과 고정을 담당합니다. 새 얇은 탄성팔을 추가하지 않았고 원래 사각 키의 휨 여유 홈은 메우지 않았습니다. 눈에 보이는 얇은 수치적 끝 모서리와 실제 힘을 받는 원형 뿌리 두께는 검사에서 구분합니다.

수납 게이지와0~225mm 서랍 경로, 클립0~90° 표본은 통과했습니다. 단계 사이에는 기존 딸깍 돌기의 의도된 강체 겹침이 남고, 원래 채널로 돌기를 눌렀다는 경로 대체모델을 사용합니다. 원본 겹침과 대체모델 결과는 `qc/assembly.json`에 함께 보존하며 힘·피로 검증으로 표현하지 않습니다. 반원 자리와 원형 앞쪽 결합부는 실제 강체 메시로 별도 검사했습니다.

앞콘이 원형으로 닫힌 R22의 수직 콕 인출 제한은 이번 뚜껑 결합부 수정으로 해결한 것이 아닙니다. 기존 첫 콕 수직 인출은 높이10/30mm에서 내관과 겹치므로 GIF는 잠금 해제·6단계 서랍 인출까지만 보여줍니다. 개별 콕 후퇴·기울임·깃털 간 마찰·손 접근은 미검증입니다. 게이지는 길이225mm·지름64mm·포갬28mm의 가정이며 실제 브랜드6개 실측이 아닙니다.

몸통 두 조각은 내부 직선 끼움·외부 물결 음양 접합으로 방향을 맞춰 접착합니다. 내관을 넣은 후 바깥에서 좌우 멈춤블록을 장착합니다. 별도 뚜껑의 자리는 전체 원형으로 확장했고 깊은30mm 사각 키는 유지합니다. 앞콘·뒤쪽 반원은 내관에 일체형입니다.

클립: **M3×20mm 볼트2개·일반M3 너트2개·금속 스페이서 외경6×내경3.2×길이6.8mm2개**, 축 구멍Ø3.4mm. 볼트를 조일 때 움직이는 링을 직접 압착하지 않도록 스페이서를 고정합니다.

양옆 멈춤면 합계56.79mm², 표본 틈0.200mm. 가정30N 정적 인출의 평균 면압0.528MPa, 한쪽만 받으면1.057MPa입니다. 고리 단순 보 가정20N의 응력9.375MPa·처짐0.1065mm입니다. 충격·피로·적층·응력 집중을 반영한 허용 하중이 아닙니다.
