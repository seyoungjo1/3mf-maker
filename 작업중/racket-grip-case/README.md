# racket-grip-case — 배드민턴 라켓 손잡이(G5) 보관 케이스 (비늘 적층섬유)

무거운 통이 라켓에 부딪혀 덜그럭거리던 문제를 **가벼운 비늘(타일) 적층섬유가 손잡이를 감싸는 방식**으로 바꾼다.

- **v2 (현재, `scripts/build.py`)**: 사용자가 말한 적층섬유 = **비늘·타일 연결**. 6×6 사각 타일(높이 1.6, 윗 모서리 0.4 챔퍼)을 틈 3 으로 놓고, **첫 2층(0.4 mm) 막**이 타일 사이를 이어 한 장으로 휜다. 막은 늘어나지 않으므로 통은 **펼칠 수 있는 원뿔**(안 반경 아래 16.41 → 위 15.21)이고, 출력 판은 그 전개도(반경 2270 호 — 거의 직사각형)다. 띠·막·타일이 **한 조각**.
- v1 (`scripts/build_v1_links.py`, 폐기): 출력 중 맞물리는 체인메일형 링크 — 사용자 의도와 다름("그 섬유 아닌데").
- **위 조임띠(해제 탭)**: 손잡이 위쪽을 조인다(2 mm 한 칸, 헐거움 둘레 95.6 → 끝까지 85.5). 빼려면 탭을 밀어 풀고 끝(뽕) 쪽으로 당겨 뺀다.
- **아래 조임띠(탭 없음 = 영구)**: 캡 목의 홈에 물려 **캡과 천이 분리되지 않는다**. 머리는 캡 노치(45°)에 맞춰 조인다. 띠 ~ 첫 타일 줄은 열마다 따로 떨어진 막 탭(캡 위 턱 1.0 을 넘어 휨).
- **캡**: 뽕 자리(끝 여유 4) → 층당 0.1 경사 → 목(옆 여유 2) → 홈 + 위 턱(층당 0.1).
- 래칫: 꼬리 옆 가장자리 톱니 + 머리 안의 혀(XY 평면에서 휨 = 층과 나란히 휨). 조임 방향은 경사, 풀림 방향은 수직면에 걸림.

## 출력 조건
- Bambu P1S · PLA · 층 0.2 · 노즐 0.4 · 코끼리발 보정 0.15 → 첫 층 +0.15 선반영(`tools/efc.py`, build.py 가 함)
- **첫 2층(막) 은 0.2 층으로 그대로** — 막 두께 0.4 = 2층. 막 쪽(베드 면)이 감았을 때 안쪽(손잡이 쪽).
- 서포트 위치: 없음(한쪽 지지 오버행 0 — 타일은 안쪽으로 좁아지는 챔퍼, 띠 머리 지붕은 양쪽 지지 브리지 6.8, 캡 목·턱은 층당 0.1)
