# racket-grip-case — 배드민턴 라켓 손잡이(G5) 보관 케이스 (적층섬유)

무거운 통이 라켓에 부딪혀 덜그럭거리던 문제를 **가벼운 적층섬유(프린트인플레이스 패브릭) 원통이 손잡이를 감싸는 방식**으로 바꾼다.
- **천**: A(우리: 바닥 링 + 모서리 기둥 + 윗 링 브리지)와 B(가운데 기둥 + 팔 브리지 + 끝 기둥)를 체커보드로 배열. B 의 팔이 이웃 A 의 옆 창을 지나고, 끝 기둥이 A 안에서 아래·위 막대에 걸려 빠지지 않는다. 출력 중에 이미 맞물린 채로 찍힌다(모든 면 수직 + 양쪽 지지 브리지 → 한쪽 지지 오버행 0).
- **위 조임띠(해제 탭)**: 손잡이 위쪽을 조여 흘러내리지 않게 한다. 빼려면 탭을 밀어 풀고 끝(뽕) 쪽으로 당겨 뺀다.
- **아래 조임띠(탭 없음 = 영구)**: 캡 목의 홈에 물려 **캡과 천이 분리되지 않는다**. 머리는 캡 노치(45°)에 맞춰 조인다.
- **캡**: 뽕 자리(끝 여유 4) → 목(옆 여유 2) → 홈 + 위 턱.
- 래칫: 꼬리 옆 가장자리 톱니 + 머리 안의 혀(XY 평면에서 휨 = 층과 나란히 휨, Z 적층 약점 없음). 조임 방향은 경사, 풀림 방향은 수직면에 걸림.
