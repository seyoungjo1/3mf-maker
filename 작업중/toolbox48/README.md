# Toolbox48 — 명판 48장 툴박스 (Toolbox42 v7)

사용자 명판(`sample/nameplate_50x30x7_EtoA.3mf`, 50×30×7)을 **긴 변 아래로 세워 U자 홈에 얹고 앞뒤로 피치 7.0 으로 겹쳐** 꽂는 상자. v5(42장 = 칸 6개 × 7장)의 칸 깊이를 58.0(8장 × 7.0 + 여유 2.0)으로 늘려 **48장**. 경첩·손잡이 귀·걸쇠 귀·탭·U자 홈 단면은 v5 그대로.

## 설계 치수표 (v7)
| 항목 | v5 (42장) | v7 (48장) | 근거 |
|---|---|---|---|
| 칸 깊이(앞/뒤) | 50.0 / 50.0 (칸막이 131.79~134.79, 3.0) | **58.0 / 58.0** | 8 × 7.0 + 2.0(장당 0.25). 명판 피치 7.0 = 본체 6.0 + 테두리 띠 1.0 (실측) |
| 칸 폭(U자 홈, 바닥/위) | 37.6 / 51.0 | 그대로 | 명판 끝단 R10 과 전 높이 0.6~1.0 여유 (`studies/nameplate-sample.md`) |
| 바닥~뚜껑 천장 | 30.9 | 그대로 | 명판 높이 30 + 0.9 |
| 본체 바깥 y | 60.0~196.0 (136) | 60.0~212.0 (152.0) | 앞칸 +8.0(절단 y=106.75), 뒷칸 +8.0(절단 y=159.75, 칸막이 노치 중심, ±1 mm 단면 동일) |
| 뚜껑 y | 65.0~191.0 | 65.0~207.0 | 같은 두 평면(뚜껑 좌표 154.06 / 101.06)에서 늘림, 로고 +8.0 |
| 경첩 축 | y 192.39, z 26.5 | y 208.39, z 26.5 | 너클·귀 치수 불변, 위치만 +16.0 |
| 손잡이·걸쇠 귀, 탭 | — | 불변 | 앞쪽(y<82)은 절단면 앞이라 이동 없음 |
| 뚜껑 끼움(립) | 0.20 (스커트 안쪽면 ↔ 립 바깥면, 닫힘 실측) | **0.30** | 본체 립 바깥면만 0.1 깎음(립 1.6 → 1.5; 립 안쪽면엔 뚜껑이 없음), 사용자 "열 때 뻑뻑" |
| 본체 바닥 곡선 | 층당 0.18 (규칙 밖) | **층당 ≤ 0.115** | z<1.51 재로프트, 첫 층 EFC +0.15 선반영(`tools/efc.py`) |
| 서포트(설계상 돌출) | 손잡이 귀쌍 밑면 z 13.5, 뚜껑 경첩 귀 돌기 밑면 z 8.3 | 그대로 | 슬라이서 서포트 "빌드 플레이트에만" |

## 파일
- `models/Toolbox48_v7_A_base_handle_latch.3mf` 플레이트 A(본체·손잡이·걸쇠), `models/Toolbox48_v7_B_lid_logo.3mf` 플레이트 B(뚜껑+로고, 필라멘트 2), 파트 STL.
- `scripts/build_v7.py` 생성, `scripts/assembly_v7.py` 조립 정의, `pipeline_v7.json` 파이프라인 설정, 결과 `qc/v7/REPORT.md`.
- 재현: `python scripts/build_v7.py ../toolbox42/v5parts.pkl ../toolbox42/lid_v6.pkl && python ../../tools/pipeline.py pipeline_v7.json`
