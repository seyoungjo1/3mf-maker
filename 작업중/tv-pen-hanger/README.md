# tv-pen-hanger v5 — 75TR3DQ 펜 자석 거치대용 걸이 (리모컨 + 펜 2, 한 덩어리)

LG 75TR3DQ 펜 자석 거치대에 **Ø20×1 자석 5개**(뒷면 원형 포켓, 접착)로 붙는 한 덩어리 걸이. 위에는 **MRSVI M5 리모컨**을 세워 꽂고,
아래에는 **J 고리 2개를 위아래로** 두어 펜을 하나씩 얹는다. 펜 몸통에 자력이 있어서(사용자) J 바닥 아래에 **Ø10×2 자석을 J 마다 3개** 숨겨 펜이 '착' 붙는다(얹는 게 주, 자석은 느낌).
옆 단면 하나를 폭 167 로 민 형상 — **옆으로 눕혀(단면이 베드) 출력**, 서포트 0.

## 자석 (`python tools/mm.py magnet …`, 거울상·링 적분 — 이상적 두꺼운 철판 상한 × 0.5 = 설계값, μ 0.3)
**TV 쪽 5개** — 하중 261 g(걸이 148(통짜 상한) + 펜 2 × 20(가정) + M5 58 + 자석 15), 무게중심 앞 12, 피벗 → 자석 47.

| 자석 앞면 ↔ 거치대 면 간격 | 1개 흡착력(이상) | 5개 설계 흡착력 | 미끄러짐 안전율 | 떼어짐 안전율 |
|---|---|---|---|---|
| 0.1 (포켓 +0.1, 거치대 면이 철판·자석 바로 앞) | 10.5 N | 26.2 N | **3.1** | 40 |
| 0.5 | 5.5 N | 13.7 N | 1.6 | 21 |
| 1.1 (거치대 자석이 1 mm 덮개 뒤) | 3.2 N | 7.9 N | **0.9** | 12 |

- 통짜 무게는 상한(실제 채움 15 % 면 걸이는 그 절반 정도) — 실제 안전율은 표보다 크다. 그래도 거치대 자석이 덮개 뒤라면 아래로 당겨 보고, 밀리면 뒷면에 미끄럼 방지 시트.
- 거치대 안 자석이 Ø10(사용자)이라 실제 힘은 Ø20 ↔ 두꺼운 철판 계산보다 작을 수 있다. 극 방향: 거치대에 대 보고 끌리는 면을 밖으로.

**펜 자석** Ø10×2 ↔ 펜 몸통: 살 1.3 너머. 펜 속 자석 크기는 모름 → 철판이라 치면 1개 3.1 N(간격 1.3, 이상) — 펜 20 g(0.2 N)의 여러 배라 '착' 붙는 느낌은 충분, 꺼낼 때 손으로 쉽게 뗀다. 극 방향: 펜을 대 보고 끌리는 면이 위로 오게 넣는다.

## 출력 조건
- Bambu P1S · PLA · 층 0.2 · 노즐 0.4 · 코끼리발 보정 0.15 → 첫 층 +0.15 선반영(`tools/efc.py`, build.py 가 함)
- 방향: **옆으로 눕혀 단면이 베드**, 폭 167 이 출력 높이. 높이/폭이 커서 **브림 5 mm**.
- 서포트 위치: **없음**. TV 쪽 원형 포켓 천장은 깊이 1.1 의 짧은 걸침, 숨은 슬롯 지붕은 2.1 폭 브리지(QC 표).
- **일시정지 3번**: 43.8 · 88.8 · 133.8 mm 층까지 출력 후 멈춤 → 위·아래 J 슬롯에 Ø10×2 자석을 세워 떨어뜨림(펜에 끌리는 면이 펜 쪽) → 재개.
- TV 쪽 자석: 출력 뒤 뒷면 포켓에 순간접착제 → 극 방향 확인 후 눌러 넣음.
