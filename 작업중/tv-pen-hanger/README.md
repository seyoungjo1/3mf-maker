# tv-pen-hanger v6 — 75TR3DQ 아래로 접어 넣는 걸이 (리모컨 세움 + 펜 2, 한 덩어리)

LG 75TR3DQ 앞면의 펜 자석 거치대에 **Ø20×1 자석 5개**로 붙는 앞판에서 **TV 밑면 아래로 꺾여 들어가**, 리모컨(MRSVI M5, 세움)과 펜 2개를
TV 밑에 매단다. **앞판 앞면보다 앞으로 나오는 수납물이 없다**(사용자). 선반이 TV 밑면에 걸쳐 무게를 TV 가 받고, 자석은 앞판을 TV 면에 붙여 둔다.
펜 J 고리 바닥 아래에 **Ø10×2 자석을 J 마다 3개** 숨겨 펜이 '착' 붙는다(펜 몸통에 자력, 사용자 — 얹는 게 주, 자석은 느낌).
옆 단면 하나를 폭 167 로 민 형상 — **옆으로 눕혀(단면이 베드) 출력**, 서포트 0.

## 힘
- **무게는 선반이 TV 밑면에 걸려 받는다.** 수납물 무게중심(y ≈ −5)이 TV 앞면 모서리보다 뒤라, 걸이가 돌려고 하면 앞판 위쪽이 TV 앞면을 누르는 방향 → 스스로 붙어 있다. 자석 5개는 부딪혀 앞으로 당겨질 때를 막는 역할.
- TV 쪽 자석 5개 흡착력(`mm magnet`, 이상 철판 상한 × 0.5): 간격 0.1 이면 26 N, 거치대 자석이 1 mm 덮개 뒤면 7.9 N — 걸이(통짜 상한 149 g) + 펜 2 + M5 = 약 265 g(2.6 N)보다 커서 자석만으로도 매달린다(미끄러짐은 선반이 막음).
- **펜 자석** Ø10×2 ↔ 펜 몸통: 살 1.3 너머, 철판이라 치면 1개 3.1 N(간격 1.3, 이상) — 펜 20 g(0.2 N)의 여러 배라 '착' 붙는 느낌은 충분, 손으로 쉽게 뗀다. 극 방향: 펜을 대 보고 끌리는 면이 위로 오게 넣는다.
- 거치대 안 자석이 Ø10(사용자) — TV 쪽 실제 힘은 계산보다 작을 수 있다. 극 방향: 거치대에 대 보고 끌리는 면을 TV 쪽으로.

## 출력 조건
- Bambu P1S · PLA · 층 0.2 · 노즐 0.4 · 코끼리발 보정 0.15 → 첫 층 +0.15 선반영(`tools/efc.py`, build.py 가 함)
- 방향: **옆으로 눕혀 단면이 베드**, 폭 167 이 출력 높이. 높이/폭이 커서 **브림 5 mm**.
- 서포트 위치: **없음**. TV 쪽 원형 포켓 천장은 깊이 1.1 의 짧은 걸침, 숨은 슬롯 지붕은 2.1 폭 브리지(QC 표).
- **일시정지 3번**: 43.8 · 88.8 · 133.8 mm 층까지 출력 후 멈춤 → 위·아래 J 슬롯에 Ø10×2 자석을 세워 떨어뜨림(펜에 끌리는 면이 펜 쪽) → 재개.
- TV 쪽 자석: 출력 뒤 앞판 뒷면 포켓에 순간접착제 → 극 방향 확인 후 눌러 넣음.
