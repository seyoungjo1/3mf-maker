# tv-pen-hanger — 75TR3DQ 펜 자석 거치대용 걸이대 (펜 2 + MRSVI M5 에어마우스)

LG 75TR3DQ 의 펜 자석 거치대에 **Ø20×1 자석 3개**로 붙이고, 아래쪽 홈에 **펜 2개**와 **MRSVI M5 에어마우스**를 눕혀 거는 걸이대.
옆 단면 하나를 폭 110 으로 민 형상이라 **옆으로 눕혀(단면이 베드) 출력** — 모든 벽이 수직이라 서포트 0, 홈이 층과 평행한 평면에서 휘어 강하다.

## 자석 고정력 (`python tools/mm.py magnet …`, 거울상·링 적분 — 이상적 두꺼운 철판 상한 × 0.5 = 설계값)
하중 185 g(걸이대 통짜 74 g 상한 + 펜 2 × 20 g + 마우스 70 g, 펜·마우스는 **가정**), 무게중심 앞 25 mm, μ 0.3(PLA·니켈 ↔ 도장면 추정).
떼어짐 피벗: 뒷판 아래 모서리가 TV 면에 닿으면 46, 거치대 아래 모서리에서 뜨면 12.5.

| 자석 앞면 ↔ 거치대 면 간격 | 1개 흡착력(이상) | 3개 설계 흡착력 | 미끄러짐 안전율 | 떼어짐 안전율(피벗 46 / 12.5) |
|---|---|---|---|---|
| 0.1 (이 설계: 포켓 +0.1) | 10.5 N | 15.7 N | **2.6** | 15.9 / 4.3 |
| 0.5 | 5.5 N | 8.2 N | 1.4 | 8.3 / 2.3 |
| 1.1 (거치대가 1 mm 덮개 뒤 자석일 때) | 3.2 N | 4.7 N | **0.8** | 4.8 / 1.3 |

자석 5개면 간격 0.1 에서 미끄러짐 4.3, 간격 1.1 에서 1.3.

- 결론: 자석이 거치대 면에 **거의 맞닿으면(간격 ≤ 0.2) 3개로 버팀**(미끄러짐 2.6배). 떼어짐보다 **아래로 미끄러짐**이 먼저 온다.
- 거치대 면이 덮개(≥ 0.5 mm) 뒤에 있는 자석이면 3개로는 모자람(1 mm 덮개면 0.8배 = 미끄러져 내려옴) → 자석 4~5개, 또는 N52 급(같은 간격 1.5배), 또는 뒷면 미끄럼 방지 시트.
- 거치대가 자석이면 **극 방향**을 맞춰야 붙는다(반대면 밀어냄). 붙이기 전에 자석을 거치대에 대 보고 붙는 면을 표시한 뒤 그 면이 밖으로 오게 접착.

## 출력 조건
- Bambu P1S · PLA · 층 0.2 · 노즐 0.4 · 코끼리발 보정 0.15 → 첫 층 +0.15 선반영(`tools/efc.py`, build.py 가 함)
- 방향: **옆으로 눕혀 단면(ㄴ+U 모양)이 베드**, 폭 110 이 출력 높이. 바닥 접지 602 mm²(첫 층 100 %).
- 서포트 위치: **없음**(오버행 0 · 브리지 0 — QC). 자석 포켓은 출력 위쪽으로 뾰족한 눈물방울이라 서포트 없이 닫힌다.
- 자석: 출력 뒤 포켓에 순간접착제 한 방울 → 자석을 극 방향 확인 후 눌러 넣음(앞면이 뒷면에서 0.1 들어감).
