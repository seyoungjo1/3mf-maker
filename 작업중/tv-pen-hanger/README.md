# tv-pen-hanger v4 — 75TR3DQ 펜 자석 거치대용 리모컨 걸이 + J 펜 홀더

두 파트. **리모컨 걸이**(MRSVI M5 를 세워 꽂음)는 LG 75TR3DQ 펜 자석 거치대에 **Ø20×1 자석 5개**(뒷면 열린 포켓, 접착)로 붙고,
**펜 홀더**(J 고리 2개를 위아래로 세운 모양, 펜 1개씩)는 리모컨 걸이 **밑면에 Ø20×1 자석 3쌍**으로 붙는다. 결합 자석은 살 1.3 mm 속에 묻혀 보이지 않는다(출력 중 일시정지 후 넣음).
두 파트 모두 옆 단면 하나를 폭 167 로 민 형상 — **옆으로 눕혀(단면이 베드) 출력**, 서포트 0.

## 자석 고정력 (`python tools/mm.py magnet …`, 거울상·링 적분 — 이상적 두꺼운 철판 상한 × 0.5 = 설계값, μ 0.3)
**TV 쪽 5개** — 하중 250 g(걸이 62 + 홀더 72(통짜 상한) + 펜 2 × 20(가정) + M5 58 + 자석 11 × 2), 무게중심 앞 15, 피벗 → 자석 47.

| 자석 앞면 ↔ 거치대 면 간격 | 1개 흡착력(이상) | 5개 설계 흡착력 | 미끄러짐 안전율 | 떼어짐 안전율 |
|---|---|---|---|---|
| 0.1 (열린 포켓 +0.1, 거치대 면이 철판·자석 바로 앞) | 10.5 N | 26.2 N | **3.2** | 33 |
| 0.5 | 5.5 N | 13.7 N | 1.7 | 17 |
| 1.1 (거치대 자석이 1 mm 덮개 뒤) | 3.2 N | 7.9 N | **1.0** | 10 |

**결합 3쌍(묻힘)** — 자석끼리 면 간격 2.6 = 철판 간격 1.3 과 같은 힘(거울상 원리): 1쌍 2.7 N(이상), 3쌍 설계 4.1 N vs 홀더+펜 115 g(1.13 N) → **당김 안전율 3.6**. 노출(간격 0.1)이었다면 13.9 — 묻어서 약 1/4 로 줄었지만 버팀.

- 거치대 안 자석이 Ø10(사용자)이라 실제 힘은 Ø20 ↔ 두꺼운 철판 계산보다 작을 수 있다(작은 자석 쪽이 힘을 정함). 덮개 뒤 자석이면 5개도 미끄러짐 1.0 — 붙여서 손으로 아래로 당겨 보고 밀리면 뒷면에 미끄럼 방지 시트.
- 극 방향: TV 쪽 5개는 거치대에 대 보고 끌리는 면을 밖으로. 결합 3쌍은 위·아래 자석을 **서로 붙여 둔 채로 짝 표시**한 뒤 넣으면 끌리는 방향이 맞는다.

## 출력 조건
- Bambu P1S · PLA · 층 0.2 · 노즐 0.4 · 코끼리발 보정 0.15 → 첫 층 +0.15 선반영(`tools/efc.py`, build.py 가 함)
- 방향: 두 파트 모두 **옆으로 눕혀 단면이 베드**, 폭 167 이 출력 높이. 높이/폭이 커서 **브림 권장**(QC 표 참고).
- 서포트 위치: **없음**(오버행 0). TV 쪽 포켓은 위로 뾰족한 눈물방울, 묻힌 슬롯 지붕은 1.1 폭 브리지.
- **일시정지 3번**(두 파트 같은 높이): 60.8 · 93.8 · 126.8 mm 층까지 출력하고 멈춤 → 걸이·홀더 슬롯에 자석을 하나씩 세워 떨어뜨림(짝끼리 극 맞춤) → 재개.
- TV 쪽 자석: 출력 뒤 뒷면 포켓에 순간접착제 → 극 방향 확인 후 눌러 넣음.
