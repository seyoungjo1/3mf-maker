# digit-counter — 기계식 7세그먼트 4자리 점수판 00:00 (8 × 20 cm)

왼쪽 점수(모듈 A)·오른쪽 점수(모듈 B)를 각각 두 자리로 센다.
- **+1**: 윗면 버튼을 누르면 1씩 오른다. 09→10 은 자리올림이 되고, 99 에서는 더 오르지 않는다.
- **−1·리셋**: 옆면 노브(A 는 왼쪽, B 는 오른쪽)를 뒤로 한 칸(36°) 딸깍 돌리면 1씩 내려간다. 10→09 는 빌림이 된다. 계속 돌리면 00 에서 걸려 더 안 돈다(= 리셋).
- **노브와 버튼**: 노브는 일의 자리 드럼에 직접 물려 있다. 그래서 버튼을 눌러도 노브가 36°씩 같이 돈다.

숫자는 日 자 7세그먼트이고, 세그먼트는 **두 상태(이진)**로만 움직인다. 셔터가 아래(켜짐)에 있으면 앞판 슬롯에 노란 줄이 보이고, 3 mm 위(꺼짐)로 가면 줄이 슬롯 위 살 뒤로 숨어 검정 홈이 보인다.

사용자 결정:
- 2026-10-22: 가로 200×80 · 日 자 7세그먼트 · 안쪽 부품 2상태 + 캠축 · 색은 층 바꿈 2색(AMS 없어도 됨).
- 2026-10-23: 4자리 00:00 점수판(B안) · ±1 · "뒤로 딸깍 = −1, 끝까지 = 00 멈춤" · 폭 200×80 · 숫자 60 mm 유지.

## 작동 원리 (모듈 하나, x 는 모듈 중심 기준)

### 표시
- 자리마다 셔터 7개(세그먼트 a~g)가 앞판(슬롯 2 / 피치 5.5)과 가운데 판(빗) 사이에서 위아래로만 3 mm 움직인다.
- 셔터 뒤 스템이 캠축 위로 넘어가, 코로 캠 디스크에 얹힌다(무게로 내려옴).

### 캠축
- 자리마다 캠 디스크 7장을 D 관 코어에 끼운다.
  - r 9 = 켜짐, r 12 = 꺼짐.
  - 숫자마다 36° 구역이고, 평탄 구간은 ±8°.
- 한 번 셀 때 드럼이 −36° 돈다.

### +1 (버튼)
- 버튼 플런저는 축 뒤 y = 축 + 13 선을 따라 수직으로 내려간다.
- 판스프링 팔 끝의 폴 이가 R1 래칫 면을 아래로 민다.
  - 정지 위치에서는 폴이 R1 끝원 밖(0.81 mm)에 있다. 그래서 노브를 자유롭게 돌릴 수 있다.
  - 누르면 일의 자리가 39.7° 돈다. 별 멈춤쇠가 36°로 맞춘다.
  - 올라올 때는 팔이 이 등을 타고 넘는다(δ 1.34).
- R1 면은 갈고리(끝이 +5°)라서, 밀 때 폴이 빠지지 않는다.

### −1·리셋 (노브)
- 노브 → 육각 축 → 일의 자리 코어(육각 구멍).
- 십의 자리 코어는 둥근 구멍이라 축 위에서 자유롭게 돈다.

### 자리올림·빌림 (주행거리계식 전달 피니언 8T, `scripts/carry.py`)
- **십의 자리 쪽**: 20T 기어.
- **일의 자리 쪽**: 평면이 둘이다.
  - **L(잠금 링 r 16.03 + 홈)**: 피니언 긴 이 둘이 링을 사이에 끼워 피니언과 십의 자리를 잠근다.
  - **C(허브 r 13.37 + 자리올림 이 r 16.18)**: 자리올림 이 끝이 잠긴 긴 이 끝(16.48)보다 낮다. 그래서 평소에는 그 밑을 지나간다.
- **이가 피니언을 미는 구간**: 일의 자리 9↔0 사이의 36° 동안에만, C 의 이가 피니언의 S 이(축을 향한 이)를 민다.
  - 피니언 90° = 십의 자리 36°.
  - 셀 때와 되감을 때 모두 같다(자리올림·빌림).

### 00 멈춤
- 십의 자리 별 바깥에 멈춤 돌기(r 10.3~12.5, 14°)가 있고, 가운데 판 뒷면에 탭(축 앞 180°)이 있다.
- 숫자 0 과 9 사이에서만 돌기가 탭을 만난다.
  - 00 에서 뒤로 돌리면 2.4° 에서 걸린다.
  - 99 에서 버튼을 누르면 2.4° 에서 걸린다.
- 이 경우 일의 자리도 1~4° 만 움직이고, 멈춤쇠가 제자리로 돌린다.

### 멈춤쇠
- 자리마다 별 디스크(10 홈)와 바닥 판스프링이 있다.
