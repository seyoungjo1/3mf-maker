# digit-counter — 기계식 7세그먼트 두 자리 카운터 (8 × 20 cm)

윗면 **+1 버튼**을 누를 때마다 숫자가 1씩 오르고(09→10 은 자리올림, 99→00), 오른쪽 옆면 **리셋 노브**를 시계 방향으로 한 바퀴 돌리면 00 이 된다.
숫자는 日 자 7세그먼트이고, 세그먼트는 **두 상태(이진)**로만 움직인다. 셔터가 아래(켜짐)에 있으면 앞판 슬롯에 노란 줄이 보이고, 3 mm 위(꺼짐)로 가면 줄이 슬롯 위 살 뒤로 숨어 검정 홈이 보인다(책상 위에서 내려다봐도 꺼짐이 비치지 않게).
사용자 결정(2026-10-22): 가로 200×80 · 日 자 7세그먼트 · 안쪽 부품 2상태 + 캠축 · 윗면 +1 · 옆면 리셋 노브 · 색은 층 바꿈 2색(AMS 없어도 됨).

## 작동 원리
- **표시**: 자리마다 셔터 7개(세그먼트 a~g)가 앞판(슬롯 2 mm / 피치 5.5)과 가운데 판(빗) 사이에서 위아래로만 3 mm 움직인다. 셔터 뒤 스템이 캠축 위로 넘어가 코(r 1.5)로 캠 디스크에 얹힌다(무게로 내려옴).
- **캠축**: 자리마다 캠 디스크 7장(r 9 = 켜짐, r 12 = 꺼짐, 숫자마다 36° 구역, 평탄 ±8°)을 D 관 코어에 끼운다. 한 번 셀 때 드럼이 -36° 돈다.
- **+1**: 윗면 버튼(플런저) → C 갈고리가 레버 패드를 40° 내린다 → 레버의 판스프링 폴 P1 이 일의 자리 래칫 R1 을 36°(+틈 2°·넘침 2°) 민다.
- **자리올림(마스크 폴)**: 폴 P2 는 평소 일의 자리 마스크 M1 테(r 15.8)에 얹혀 톱니(끝 r 15.0) 위로 떠 있다. 일의 자리가 9 일 때만 마스크 홈에 떨어져 십의 자리 래칫 Rc 를 함께 민다. 바퀴끼리 늘 물려 있지 않아서 리셋이 각 자리를 따로 돌릴 수 있다.
- **리셋(탈리 카운터 방식)**: 육각 축에 홈이 하나 있다. 코어 관 끝의 판스프링 키가 셀 때는 홈을 미끄러져 넘고, 노브를 셀 때와 같은 방향으로 돌리면 홈 벽이 각 드럼의 키를 차례로 걸어 끌고 간다. 한 바퀴를 돌면 두 자리 모두 0 에서 멈춘다.
- **멈춤쇠**: 자리마다 별 디스크(10 홈)와 바닥 판스프링이 있다. 축에도 별 칼라와 판스프링이 있어 셀 때 축이 끌려 돌지 않는다.

## 출력 조건
- Bambu P1S · PLA · 층 0.2 · 노즐 0.4 · 코끼리발 보정 0.15 → 첫 층 +0.15 선반영(`tools/efc.py`, build.py 가 함)
- 플레이트 5장: P1 본체·뚜껑(검정) / P2 앞판·가운데 판(검정) / P3 셔터·스템(검정, **2.4 mm 층에서 노랑으로 바꿈**) / P4 기구(회색) / P5 노브·버튼 캡(노랑)
- 서포트: 없음(QC 오버행 0 목표). 스템은 2 mm 납작한 판이라 바닥 접지 82~178 mm² — 브림 3 mm 권장.
