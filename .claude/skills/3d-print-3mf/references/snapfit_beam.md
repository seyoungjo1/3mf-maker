# 스냅핏·휨 계산 (tools/snapfit.py, tools/beam.py)

캔틸레버 스냅(두께 t, 길이 L, 폭 b, 걸림 깊이=팁 변위 Y, E, 뿌리 유연계수 Q=1.0~2.0, 기본 1.5):
- 변형률 ε = 1.5·t·Y/(L²·Q) → PLA 허용: 1회 4~8 %, 반복 2~4 %, Z방향 적층 ×0.5
- 팁 힘 P = b·t²·E·ε/(6·L·Q),  삽입력 W = P(μ+tanα)/(1−μ·tanα) (α 리드각, μ≈0.3), 분리력은 리턴각으로(90°면 ∞ = 젖혀야 빠짐)
- 토크(경첩형 걸쇠) T = P × (피벗~걸림턱 거리). 손 조작 목표: 삽입 10~30 N, 토크 0.1~0.4 N·m
- 사례(Toolbox42): 현재 걸쇠 암 L16·t4.5 → 1.5 mm 걸림에 155 N(불가). L25·t3.0 → 12 N 삽입·40 N 분리(리턴 60°)·토크 0.17 N·m(적정)

보 처짐: I = b·h³/12. 캔틸레버 δ=PL³/3EI, 단순지지 δ=PL³/48EI, 양단고정 δ=PL³/192EI. 응력 σ=M(h/2)/I, PLA 인쇄물 안전 25 MPa.
- 손잡이 가로대 76 mm, 12.7×9, 20 N → 0.07 mm. 다리 25 mm, 5.4×9, 10 N → 0.13 mm(2.7 mm였을 때 1.07 mm, 23 MPa)
