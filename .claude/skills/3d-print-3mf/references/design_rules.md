# 설계 규칙 (FDM, 0.4 노즐, 0.2 층, PLA) — 출처는 sources.md

| 항목 | 값 | 근거·메모 |
|---|---|---|
| 최소 벽 | 1.2 mm (3 perimeter); 0.8 mm는 장식용 한계 | 노즐 폭 배수로. 1.0 mm 미만은 slicer가 벽을 못 채움 |
| 휘는 부재(다리·암·클립) | ≥ 3 mm, 길이/두께 5~10 | 2.7 mm 다리는 처짐 1.1 mm/10 N·응력 23 MPa(한계 근접). 5.4 mm면 0.13 mm |

| 첫 층 | 접지 ≥ 첫 층 면적 70 %·≥ 100 mm²; 코끼리발 챔퍼 0.3~0.5; 긴 판 모서리는 브림/마우스귀 | 접지 7 mm² 걸쇠가 오그라든 실제 사례 |
| **오버행 규칙은 출력물 기준** | 층당 바깥 이동 ≤ 0.115 mm — 모델이 아니라 **슬라이서가 깎은 뒤**의 윤곽으로 센다 | 사용자 프로파일: 코끼리발 보정 0.15, 첫 층 선폭 0.5. 모델 1→2층 0.115 + 보정 0.15 = 출력물 0.265 → 2층이 허공에 쌓여 눌림(Toolbox42 뚜껑 v5 실패 원인). 첫 층을 모델에서 보정값만큼 미리 키우거나(EFC 0.15 전용 파일) 보정 0으로 출력 |
| **애매한 오버행 금지** | 층당 0.115 초과 ~ 0.25 미만(30°~50°)은 **설계 금지** | 깨끗이 쌓이지도 않고 슬라이서가 서포트를 놓지도 않는 구간. 본체 바닥 곡선(0.18/층)이 이 구간 — 기준 파트라도 규칙 밖이면 그대로 복제하지 말고 ≤0.115로 고쳐 쓴다 |
| **서포트 정책** | 설계상 돌출(경첩 돌기 밑면, 귀 등)은 서포트를 쓴다 — 지저분해도 쓴다. 보이는 면·곡선은 서포트 없이 ≤0.115로 설계 | 둘 중 하나로 확실히: "서포트 대는 곳" 또는 "규칙 안". 중간은 없다 |
| **멀티컬러 플레이트** | 색 바꿈(프라임 타워·플러시)으로 층 시간이 길어 이미 식은 위에 쌓는다 → 오버행·브리지 허용치를 더 줄인다: 첫 5층(1 mm)은 오버행 0, 곡선 시작은 그 위에서 | 뚜껑 로고 인레이가 첫 3층에 있어 가장 식은 상태에서 모서리를 쌓았다 |
| **뒤집어 출력하는 윗면 모서리** | 바닥에서 ≥ 0.8 mm(4층)는 전체 윤곽으로 수직, 그 위부터 ≤0.115/층 곡선 | 첫 층 접지 최대 + 보정 영향 구간을 수직으로 넘김 |
| 작은 부품 | 최대 치수 < 5 mm·부피 < 50 mm³ 금지 | 분실·강도·안착 모두 불리 |
| 삼각형 | 파트 ≤ 200k, 파일 ≤ 500k | Bambu Studio 지연·슬라이싱 시간, 짧은 경로로 출력 느려짐 |
