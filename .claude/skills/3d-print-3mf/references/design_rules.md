| **오버행 규칙은 출력물 기준** | 층당 바깥 이동 ≤ 0.115 mm — 모델이 아니라 **슬라이서가 깎은 뒤**의 윤곽으로 센다 | 사용자 프로파일: 코끼리발 보정 0.15, 첫 층 선폭 0.5. 모델 1→2층 0.115 + 보정 0.15 = 출력물 0.265 → 2층이 허공에 쌓여 눌림(Toolbox42 뚜껑 v5 실패 원인). 첫 층을 모델에서 보정값만큼 미리 키우거나(EFC 0.15 전용 파일) 보정 0으로 출력 |
| **애매한 오버행 금지** | 층당 0.115 초과 ~ 0.25 미만(30°~50°)은 **설계 금지** | 깨끗이 쌓이지도 않고 슬라이서가 서포트를 놓지도 않는 구간. 본체 바닥 곡선(0.18/층)이 이 구간 — 기준 파트라도 규칙 밖이면 그대로 복제하지 말고 ≤0.115로 고쳐 쓴다 |
| **서포트 정책** | 설계상 돌출(경첩 돌기 밑면, 귀 등)은 서포트를 쓴다 — 지저분해도 쓴다. 보이는 면·곡선은 서포트 없이 ≤0.115로 설계 | 둘 중 하나로 확실히: "서포트 대는 곳" 또는 "규칙 안". 중간은 없다 |
| **멀티컬러 플레이트** | 색 바꿈(프라임 타워·플러시)으로 층 시간이 길어 이미 식은 위에 쌓는다 → 오버행·브리지 허용치를 더 줄인다: 첫 5층(1 mm)은 오버행 0, 곡선 시작은 그 위에서 | 뚜껑 로고 인레이가 첫 3층에 있어 가장 식은 상태에서 모서리를 쌓았다 |
| **뒤집어 출력하는 윗면 모서리** | **연속 곡선**(본체 바닥과 같은 ≤0.115/층 곡선)을 쓰고, 멀티컬러 인레이가 있는 첫 3층(0.6 mm)만 **곡선 시작 inset 자리에서** 수직. 첫 층은 `efc.py` 로 +0.15 선반영 | 전체 윤곽으로 수직 띠를 깔면 1.5 mm 턱(접시 테두리)이 생긴다 — Toolbox42 v6/v7 뚜껑, 사용자가 "성의 없는 디자인"으로 반려. v5 뚜껑이 들뜬 원인은 곡선이 아니라 EFC 미선반영(1→2층 0.265)이었다 |
| **벽 속 수평 틈 금지** | 벽 안에 0.4 mm 미만 수평 틈이 있으면 출력물 옆면에 줄이 생긴다. 불리언으로 잘라낼 영역은 반드시 대체 형상(로프트) 안에 들어가게 하고, 곡면은 판을 쌓지 말고 `tools/loft.py` 로 로프트 | `python tools/mm.py slits` · QC '벽 속 수평 틈'. Toolbox48 v6/v8 뚜껑 z 7.8 0.1 mm 틈(사용자 출력물 줄) |
| 작은 부품 | 최대 치수 < 5 mm·부피 < 50 mm³ 금지 | 분실·강도·안착 모두 불리 |

| **브리지 vs 오버행 구분** | 벗어난 영역의 각 점에서 8방향으로 아래층까지 거리를 재서 135°/180° 떨어진 두 방향이 모두 닿으면 **브리지**(스팬 = 두 거리 합, ≤ 7 mm 허용·멀티컬러 ≤ 5), 아니면 **캔틸레버(금지)** | `tools/overhang.py classify`, QC 표의 "오버행(한쪽)"과 "브리지(최대 폭)" 열. 한쪽 긴 변만 받친 띠(인방 바깥 2.1 mm 띠)는 기둥 사이 길이 방향 스팬(13 mm)으로 잡혀 폭 초과로 걸린다 — 실제로도 늘어진다 |
| **쌓는 부재(링·보·테두리)** | 아래 부재 윗면 **안에 완전히** 올라앉아야 한다(한 층짜리 캔틸레버 금지). 위에서 폭이 더 필요하면 **사다리꼴**로 키운다: 바깥·안쪽 면 모두 층당 ≤ 0.11 | 인정전 램프 인방: 아래 폭 3(창살 깊이) → 위 6.3, 높이 6 (0.067/0.043 per 층). 테두리(2.7)와 띠 받침(2.7)이 그 위에 올라감 |
| **발광 갓(디퓨저) 예외** | 0.8 mm 단일 벽(0.42 두 줄) 통은 허용 — QC `--single-wall 이름` 으로 의도 표시, 브림 outer only | 랜턴 샘플·인정전 램프. 그 외 벽은 ≥ 1.2 |
| **2단 계단** | 윗단 계단은 아랫단 윗면 **안쪽**에 끝나야 한다(들여쓰기 ≥ 계단 길이 + 2) | 2단 계단이 1단 밖으로 2.6 mm 나가면 한 층 캔틸레버(89 mm²) |
| **EFC 선반영** | 출력 방향 메시의 첫 층(0~0.2)을 `tools/efc.py` 로 +0.15 키워 둔다(사용자 프로파일 코끼리발 보정 0.15). 같은 오브젝트의 색 파트가 면접촉하면 `pre_expand_first_layer_group` 으로 바깥 윤곽만 | QC 는 `--efc 0.15` 기본으로 출력물 기준 1→2층 단차를 센다. 선반영 안 한 수직 벽은 0.15 단차로 ⚠ |
| **LED 퍽 포켓** | 위에서 넣는 포켓(바닥 두께 ≥ 3) + 윗 파트(바닥판)가 덮는다 → 천장 브리지 0, 퍽 빠짐 없음. 전선은 포켓 바닥 높이의 터널(폭 6 → 브리지 6) | 아래서 넣는 포켓은 Ø61 천장 링이 5.5 브리지 + 퍽이 떨어진다(v0 폐기) |
| **디테일 최소치(장식 부재)** | 선·살 0.8(두 줄), 돌출 높이 0.6(3층), 틈 0.6, 세워진 살 1.2, 법수·작은 기둥 2.0; 보이는 면은 윗면으로 눕혀 출력; 작은 부재는 띠·판으로 묶음 | `studies/detail-design-method.md`. 취리히대 지침 부조 ≥1.0, 멜버른대 권장 1.2, 0.4 배수. 0.2 노즐이면 0.5/0.4 |
