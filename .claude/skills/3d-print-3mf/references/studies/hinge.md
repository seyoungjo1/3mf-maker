# 경첩 (2026-10)
출처: Snapmaker, Sovol, QIDI, Zbotic, MakerWorld 모델 페이지(`../sources.md`).

## 핀 경첩 (분리 핀/M3 볼트) — `tools/hinge.py`
- 구멍 = 핀 지름 + 0.3 (M3 볼트 3.4), 너클 벽 ≥ 1.6 → 너클 외경 ≈ 핀+3.9. 너클 사이 축방향 틈 0.3. 잎 두께 ≥ 2.4, 나사 구멍 3.4.
- **핀 축을 베드와 평행**하게 눕혀 출력(구멍 ≤ 4 mm 서포트 없음, 층이 축과 평행이라 너클이 갈라지지 않음). 너클은 잎 모서리 바깥으로 — 회전할 때 상대 잎과 간섭 없음(각도 스윕 0~180° 간섭 0 확인).
- 토크·강도: 너클 1개당 전단 면적 = 벽 두께×길이. 뚜껑 하중 20 N 기준 충분.
- 너클 밑은 **D형**(반폭 0.866r 블록 + 원통): 원통을 그대로 눕히면 바닥 쪽이 층당 0.2~0.6 오버행(첫 시도 99 mm² 위반, 조각 분리). 잎은 너클 블록과 0.5 겹치게.
- 노치 반폭 = sqrt((블록 모서리 반경 + 0.3)² − (r − 잎 두께)²): 상대 너클의 D블록 모서리가 회전해도 잎에 안 닿는 값(예 4.75). 회전 스윕은 **잎이 위로 올라가는 방향**으로(반대 방향은 베드/상대 잎을 뚫는 것이라 의미 없음).
- 생성 예: `python tools/hinge.py --pin 3.0 --length 40 --knuckles 5 --out A.stl B.stl` → 너클 외경 6.9, 분절 7.76, QC 통과, 간섭 0·최소 간격 0.3.

## 프린트인플레이스 경첩
- 반경 틈 0.2~0.3 mm(일반), 2~3 mm 소형 너클 0.10~0.15. Z 틈 ≥ 2층(0.4). 핀 아래쪽 챔퍼/눈물방울(수평 핀).
- 융착이 1번 실패 원인 → 첫 출력은 틈 0.15/0.2/0.25/0.3 쿠폰.
- PLA는 반복 하중·열에 약해 꽉 끼는 경첩엔 PETG 권장.

## Toolbox42 적용
- 본체 뒤 너클 ⌀3.4 at (y 192.39, z 26.5), 뚜껑 귀 쌍 틈 4.8 vs 너클 4.2 → 0.3/쪽. 0~120° 간섭 0 (M3×14 볼트).
