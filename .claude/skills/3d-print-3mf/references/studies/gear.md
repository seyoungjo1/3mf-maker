# 기어·톱니 (2026-10)
출처: Fictiv, Sovol, UT Austin RMD wiki, MakerWorld 생성기 페이지, Prusa 포럼(`../sources.md`).

- **모듈 ≥ 1.0**(피치 ≥ 3.1 mm): 0.4 노즐로 이 끝이 뭉개지지 않는 하한. 잇수 ≥ 12, 17 미만은 언더컷 → 전위.
- 압력각 20° 기본(소음·강도 균형), 백래시 **0.10 mm/물림**(FDM 팽창분; 0.05 최소, 0.15/기어 관례도 있음 — 어느 기준인지 명시). 팁 여유 0.25·m, 이뿌리 필렛 0.3·m(균열 방지).
- 헤링본: 나선각 25°(20~30), 눕혀 서포트 없이, 두께 12~20·m. 프린트인플레이스 유성기어는 물림 틈 0.35.
- 축간거리 = m·(z1+z2)/2. 구멍 +0.3. 하중 기어는 PETG/나일론, 층 0.15~0.2.
- 생성기 `tools/gear.py`: 인벌류트 프로파일(기초원→팁 24점), 스퍼/헤링본(로프트), 보어 불리언, 규칙 경고. 예: m1.5 z20 w8 보어 5.3 헤링본 → 33k 삼각형, 닫힘.
- QC 메모: m1.5 는 이 끝 폭이 0.6~0.9 mm 라 "얇은 살" 경고(4.8 mm²)가 뜬다 — 이 끝이 노즐 2줄 미만이면 뭉개지므로 하중용은 **m ≥ 2**.
- 다음: 전위(profile shift) 구현, 내접 기어·랙, 쿠폰(백래시 0.05/0.10/0.15) 출력 후 값 확정.
