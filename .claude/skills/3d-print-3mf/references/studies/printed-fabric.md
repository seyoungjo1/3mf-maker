# 적층섬유(프린트인플레이스 패브릭·체인메일) — 스터디 (2026-10-13, 미검증·쿠폰 전)

사용자 정의: "3D 프린터로 여러 파츠를 이어서 한 개의 섬유처럼 하는 기법" = 출력 중에 서로 맞물린 작은 링크(타일)들이 한 번에 찍혀 천처럼 휘는 판. 용도: 배드민턴 라켓 손잡이 끝 보관 케이스 — 무거운 통이 라켓과 부딪혀 소리 나던 문제를 **가벼운 천이 중력으로 감싸는 방식**으로 해결.

## 1. 원리
- 단단한 통 + 끼움 공차(0.2~0.3/한쪽)는 그 틈이 곧 유격 → 덜그럭거림. 패브릭은 링크 사이 놀이(play)로 휘어 표면에 붙고, 질량이 작아 부딪혀도 소리가 작다.
- 휨 각도 ≈ 링크 놀이 / 링크 피치. 원통(반경 R)을 감싸려면 이음마다 회전각 ≥ 피치/R(rad) 이 나와야 한다 → 피치를 작게(8~10 mm), 놀이를 크게.

## 2. FDM 에서 오버행 없이 맞물리게 하는 구조 (이 저장소 규칙 적용안)
- **A 링크 = 상자 우리(cage)**: 바닥 사각 링(베드) + 모서리 기둥 4개 + 윗 사각 링(기둥 사이 브리지). 옆면 4개가 세로 창(window).
- **B 링크 = 기둥 5개 + 팔 4개**: 가운데 기둥과 팔 끝 기둥(베드에서 시작)이 중간 높이 팔(브리지)로 이어진다. 팔은 이웃 A 의 창을 지나고, 끝 기둥은 A 우리 안에서 창보다 위·아래로 길어 빠지지 않는다.
- A·B 체커보드 배열. 모든 면이 수직 벽 + 양쪽 지지 브리지 → 한쪽 지지 오버행 0, 브리지 ≤ 7(규칙).
- 시작값(쿠폰으로 확정): 살 폭 1.2(3줄)·두께 1.0(5층), XY 틈 0.4~0.5, Z 틈 ≥ 0.6(브리지 처짐 감안, 2층 이상), 피치 8~10.

## 3. 출처에서 확인한 것
- 링크끼리 닿지 않게 틈을 둬야 융착이 없다; 출력 길이는 겉보기보다 길다(링크가 안 닿게 펴서 찍으므로) — RapidMade.
- 작고 둥글고 촘촘한 링크일수록 천처럼 거동한다 — MIT 수업 기록. 판이 커질수록 실패 확률이 올라간다 — MakerWorld PipeLink.
- 육각 타일 + 도그본 연결(피치 13.8×11.95, 0.2 층, PLA 가능·PETG 더 관대) — MakerWorld.
- 맞물림 면 틈 0.2~0.4 가 FDM 융착 방지 범위, 0.2 반경에서 시작해 조정 — Virtual Foundry.
- 틈 값은 출처마다 근거가 약하다 → **0.3/0.4/0.5 쿠폰을 먼저 출력해 확정**한다(design-method 1.6).

## 4. 남은 것
쿠폰(틈 3종) 출력 → 휨 각도·소리·융착 확인 → 라켓 손잡이 실측(둘레·길이·버트캡) → 케이스 설계. 조립 검증은 출력 상태에서 링크 간 교집합 0·최소 간격(틈 값) + 휜 상태 포즈 몇 개의 간섭으로 한다.
