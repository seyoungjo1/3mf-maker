# 적층섬유 — 스터디 (2026-10-13, 설계 검증 완료·실물 출력 전)

**사용자 정의(확인됨): 적층섬유 = 비늘·타일 연결** — 두꺼운 타일(비늘)을 얇은 연결부로 이어 한 출력으로 나오는 유연한 판. 체인메일(출력 중 맞물리는 링크)은 **아니다** — v1 을 링크형으로 짰다가 "그 섬유 아닌데" 반려(용어를 추측하지 말고 선택지로 먼저 확인할 것).
용도: 배드민턴 라켓 손잡이 끝 보관 케이스 — 무거운 통이 라켓과 부딪혀 소리 나던 문제를 **가벼운 판이 감싸는 방식**으로 해결. 아래 §0 이 사용자 방식, §1~ 은 링크형(v1) 기록.

## 0. 비늘·타일 적층섬유 (v2, `작업중/racket-grip-case/scripts/build.py`)
- 구조: 첫 2층(0.4 mm) **막**이 판 전체에 깔리고 그 위에 타일(6×6, 높이 1.6, 윗 모서리 0.4 챔퍼 → 안쪽으로 좁아져 오버행 0). 타일 사이 틈에서 막만 휜다. 한 조각 · 서포트 없음.
- 막 굽힘 변형률 = (t/2)/r, r = 틈 / 꺾임각, 꺾임각 = 피치/반경. 막 0.4·틈 3·피치 9·반경 15.21 → 3.9 %(PLA 반복 허용 4 %). 틈 2.4 면 5.7 %(PETG 권장). 선택지는 이 식으로 표를 만들어 고르게 했다(A 6×6/틈 3 채택).
- **막은 늘어나지 않는다** → 감을 수 있는 모양은 원통·원뿔(펼칠 수 있는 면)뿐. 반경이 다른 두 고리(아래 띠 16.41, 위 15.21)를 잇는 통은 원뿔로, 출력 판은 그 전개도(반경 ρ = R/sinα, 여기선 2270 → 거의 직사각형)로 만든다. 매개 좌표(s, y, z)로 한 번 짜고 `manifold.warp` 로 출력 판(전개도)과 감은 상태를 둘 다 만든다 — 링크형처럼 행마다 반경을 바꾸면(원뿔 아닌 곡면) 막이 전단을 받아 안 된다.
- 단단한 턱을 넘는 구간(캡 위 턱 1.0)은 막을 열마다 끊어 **탭**으로 — 탭끼리 떨어져 있어 둘레가 늘어나도 된다. 첫 타일 줄은 턱 위에서 시작.
- 조임띠는 막과 한 몸(띠 가장자리에 막이 붙음). 꼬리가 머리를 지나는 구간에는 막을 붙이지 않는다(틈 0.6).
- 검증: QC 한 조각·오버행 0·브리지 6.8(띠 머리 지붕), 감은 원뿔 ↔ 캡 접촉·↔ 손잡이 1.73, 래칫 물림 교집합 0·0.17. 막 얇은 살 경고는 나오지 않았다(0.4 막 전체가 바닥 첫 2층).
- 출처: 막 2층 경첩(0.1×2 권장, PLA 가능) https://www.printables.com/model/947232-constant-thickness-flashers , 리빙 힌지 타일 https://printables.com/model/505713-flexifier-flexi-3d-models-generator-print-in-place , 타일 매트 https://makerworld.com/en/models/621081-the-tilemat-gen1-0

## 1. 원리
- 단단한 통 + 끼움 공차(0.2~0.3/한쪽)는 그 틈이 곧 유격 → 덜그럭거림. 패브릭은 링크 사이 놀이(play)로 휘어 표면에 붙고, 질량이 작아 부딪혀도 소리가 작다.
- 휨 각도 ≈ 링크 놀이 / 링크 피치. 원통(반경 R)을 감싸려면 이음마다 회전각 ≥ 피치/R(rad) 이 나와야 한다 → 피치를 작게(8~10 mm), 놀이를 크게.

## 2. FDM 에서 오버행 없이 맞물리게 하는 구조 (이 저장소 규칙 적용안)
- **A 링크 = 상자 우리(cage)**: 바닥 사각 링(베드) + 모서리 기둥 4개 + 윗 사각 링(기둥 사이 브리지). 옆면 4개가 세로 창(window).
- **B 링크 = 기둥 5개 + 팔 4개**: 가운데 기둥과 팔 끝 기둥(베드에서 시작)이 중간 높이 팔(브리지)로 이어진다. 팔은 이웃 A 의 창을 지나고, 끝 기둥은 A 우리 안에서 창보다 위·아래로 길어 빠지지 않는다.
- A·B 체커보드 배열. 모든 면이 수직 벽 + 양쪽 지지 브리지 → 한쪽 지지 오버행 0, 브리지 ≤ 7(규칙).
- 확정 치수(라켓 케이스 v1, `작업중/racket-grip-case/`): 피치 9.8, A 반폭 4.4, 막대 1.3, 바닥 막대 z 0~1.2, 윗 막대 3.6~4.6(창 2.4), B 팔 1.3 폭 z 1.8~2.8, 끝 기둥 1.3×2.0 z 0~2.8, XY 틈 0.4, Z 틈 0.6/0.8, 브리지 6.0~6.1. 두께 4.6.
- 폭이 정확히 1.2 면 QC '얇은 살'이 잡힌다(샘플링) → 1.3 으로.

## 4. 설계 검증에서 배운 것 (racket-grip-case)
1. **끝 기둥 높이가 꺾임을 막는다.** 끝 기둥을 위·아래 막대 둘 다 걸리게(z 0~4.2) 하면, 창 가운데 축으로 돌 때 기둥 모서리가 막대를 긁어 간섭 0 범위가 ±10° 뿐이었다. 끝 기둥을 팔 높이(0~2.8)까지만 두고 아래 막대에만 걸리게 하자(들림 0.8 일 때도 0.4 걸림) **−37~+10°**. 감는 데 필요한 꺾임 = 피치/반경(9.8/15.21 = 37°). `mm make` 스윕으로 확인.
2. **행마다 둘레가 다르면(원뿔) 위아래 링크가 전단을 받는다**: 같은 s 의 링크가 θ 로 어긋나는 양 ≈ (s − s_c)·ΔR/R. 링크 옆 놀이(팔이 창 안에서 ±2)를 넘지 않게 반경 변화를 여러 행에 나누고(16.41 → 15.21 을 3행), 천 가운데를 기준으로 감는다. 감은 메시(manifold `refine_to_length` + `warp`)의 A∩B 교집합 0 으로 확인.
3. 천은 직사각형으로 찍고 작은 둘레에서는 더 겹치게(겹침 = 폭 − 2πR) 둔다. 감은 그림의 겹침 오프셋은 **천 두께 + 0.4**(두께를 바꾸면 같이 바꿀 것 — 4.2→4.6 으로 바꾸고 안 바꿔 0.05 mm³ 간섭이 났다).
4. 조임띠(케이블타이식)를 출력 가능하게: 머리 터널은 띠 방향(수평)으로, 톱니는 꼬리 **옆 가장자리**(평면 톱니 = 수직 벽만), 혀는 **XY 평면에서 휘는** 외팔보(층과 나란히 휨 — Z 약점 없음), 혀 톱니는 바닥부터 세운 기둥. 띠 두께 1.0 은 반경 13.6 에 감을 때 변형률 3.5 %(≤ 4 %).
5. 띠 위의 링크 기둥은 꼬리가 머리를 지나는 구간(조인 둘레 − 머리 앞) 앞에서 끝나야 한다.

## 5. 남은 것
쿠폰(틈 3종) 출력 → 휨 각도·소리·융착 확인 → 라켓 손잡이 실측(둘레·길이·버트캡) → 케이스 설계. 조립 검증은 출력 상태에서 링크 간 교집합 0·최소 간격(틈 값) + 휜 상태 포즈 몇 개의 간섭으로 한다.
