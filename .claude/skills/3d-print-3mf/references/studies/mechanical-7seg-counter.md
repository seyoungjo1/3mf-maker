# 기계식 7세그먼트 두 자리 카운터 — 스터디 (2026-10-22, `작업중/digit-counter/`)

요청: 8×20 cm, 버튼을 누르면 숫자가 오르는 두 자리 번호판, 리셋 가능, 日 자 7세그먼트, 안쪽 부품은 이진(두 상태)으로 움직임.
출처(구조 조사): Keveney "Slotted Mechanical Seven-Segment Display"(앞판 슬롯 + 줄무늬 셔터 위/아래), Shiura 캠 7세그먼트(캠축 하나로 7 세그먼트),
Printables·MakerWorld "7 Segment Mechanical Counter v3.0"(누름 입력·고무줄 복귀). 주소는 `../sources.md` 끝.

## 1. 숫자 표시 방식 고르기 — 비례가 먼저 정해진다
| 방식 | 숫자 크기 제약 | 결과(200×80 정면) |
|---|---|---|
| 세로축 10각 드럼 | 면 폭 = 0.618·R, 숫자 간격 = 드럼 지름 → **면/간격 0.31** | 숫자 44×24 인데 두 숫자 중심이 97 mm 떨어짐(사이 70 mm) — 처음 추천했다가 계산으로 철회 |
| 가로축 드럼(주행거리계) | 숫자 높이 ≤ 0.31 × 정면 높이 | 숫자 18~20 mm |
| 스플릿플랩 | 숫자 ≈ 2 × 플랩 | 크지만 플랩 양면 그림 → AMS 또는 반쪽 40장 접착 |
| **슬롯형 7세그먼트(채택)** | 숫자 = 정면 높이의 75 % | 60×34, 두 자리 간격 15 |
→ 사용자에게 방식을 물을 때 **숫자 크기와 숫자 간격을 둘 다** 계산해 보여준다(간격을 빼고 물어 한 번 되돌림).

## 2. 슬롯형 세그먼트 (이진)
- 앞판 슬롯 2 / 피치 4. 셔터(검정 바탕 + 노란 사다리꼴 줄 0.6)가 2 mm 위 = 켜짐, 아래 = 꺼짐(검정 홈). 셔터는 출력할 때 줄을 위로 → **2.4 mm 층에서 필라멘트 한 번 바꿈**(AMS 없이 2색).
- 셔터 ↔ 스템은 따로 출력해 장부로 꽂는다: 셔터는 줄이 위, 스템은 눕혀야 하므로 한 몸으로는 출력 방향이 안 맞는다. 장부는 바닥 쪽을 평평하게 두고 반대쪽만 0.4 들인다(셔터 모서리 벽 ≥ 1.2).
- **보는 각도 = 슬롯 깊이**: 슬롯 앞면에서 줄 면까지 깊이 D 이면 위 θ 에서 내려다볼 때 시선이 D·tanθ 아래로 비낀다. 첫 판(앞판 3 + 틈 0.4 = 3.4, 줄 = 슬롯 2 mm)은 위 30° 렌더에서 켜진 세그먼트까지 검게 보였다. → 앞판 1.6(D 2.0), 켜진 줄을 슬롯 아래로 1.0 더 길게(3.0), 피치 5.5(살 3.5), 행정 3, **켜짐 = 셔터 아래 / 꺼짐 = 위(살 뒤)**. 정면~위 26° 에서 켜짐 노랑, 꺼짐은 위쪽 어느 각도에서도 검정(아래에서 올려다보면 꺼진 줄이 비친다 — 책상·벽 위쪽 시선 전제).
- 팔로워(셔터+스템)는 무게(≈1 g)로 캠에 얹힌다. 마찰에 민감하니 시험편으로 먼저 확인한다(안 내려오면 판스프링 또는 홈 캠으로 바꾼다).

## 3. 캠축 — 한 몸 출력이 안 되는 이유와 처방
- 캠 링 7개를 한 몸으로 세워 출력하면 위 링이 아래 링보다 큰 구역이 2 mm 턱(오버행)이 된다. 세그먼트마다 극성(켜짐=높음/낮음)과 순서를 모두 바꿔 봐도(2^7 × 순열) **최소 6 구역이 남는다**(포함 사슬이 없음). → **캠 디스크를 하나씩 눕혀 출력해 D 관 코어에 끼운다**(디스크 2.8 + 보스 r 8.5).
- 보스·별처럼 디스크 위에 올리는 것은 캠 최소 반지름보다 **0.3 이상 작게**: 0.1 차이는 wallscan '가로줄'(0.02~0.3 단차)로 잡힌다.

## 4. 자리올림 = 마스크 폴, 리셋 = 탈리 카운터 키
- 주행거리계식 전달 피니언은 십의 자리를 하우징에 묶어서 리셋할 때 걸린다. **마스크 폴**(P2 가 일의 자리 마스크 테 위에 떠 있다가 9 에서만 홈에 떨어져 십의 자리 래칫을 함께 민다)은 바퀴끼리 늘 물려 있지 않아서 리셋이 자유롭다.
- P2 가 R1 위를 지나가야 하면 P1 과 **36° 배수만큼 떨어뜨린다**: R1 톱니 틈이 P2 자리에도 같은 위상으로 있어서 9 에서 P2 가 떨어져도 R1 을 같이 밀 뿐 충돌하지 않는다.
- 코어를 M1(아래)→R1(위)로 세워 출력하려면 R1 ≤ M1 이어야 한다 → **마스크 홈 바닥을 톱니 경사와 같게** 만들었다(오버행 0, P2 는 톱니 면까지 내려감).
- 리셋: 육각 축 홈 하나 + 코어 관 끝 판스프링 키. 셀 때(드럼이 축보다 앞으로) 키가 홈 경사로 빠지고, 노브를 셀 때와 같은 방향으로 돌리면 홈 걸림벽이 각 드럼을 차례로 끌어 한 바퀴 뒤 00. **축이 셀 때 끌려 돌면 십의 자리가 잘못 올라간다** → 축에도 별 멈춤쇠.

## 5. 레버·버튼 배치 규칙
- 레버는 판(베드)에서 폴 팔을 압출로 세운다(판스프링 팔이 층 안에서 휨). 판 슬랩에 팔이 같이 있으므로, **버튼 플런저가 레버 좌표계에서 쓰는 부채꼴(패드 위 90~130°)에 폴 팔을 두면 안 된다**(v1 첫 판: 레버∩플런저 38~72 mm³). 폴은 아래쪽(-72°, -108°)으로.
- 판스프링 변형률 ε = 1.5·t·δ/L²: 늘 휘어 있는 것(P2 0.66 %, 키 1.65 %)은 낮게, 잠깐 휘는 것(P1, 멈춤쇠)은 ≤ 4 %.
- 플랜지(r 15.8)가 가운데 판 앞까지 나온다 — 판에 **창**을 내고 조립 쌍(코어↔가운데 판)을 꼭 넣는다(처음엔 쌍이 없어 놓칠 뻔함).

## 6. 검증 방법(새로 생긴 것)
- 휘는 부품(폴·키·멈춤쇠)은 공칭(안 휜) 모양이라 강체 교집합이 의미 없다 → 조립 정의의 **`checks`**(파이프라인이 ⚠ 로 판정)에 2D 운동학·변형률을 넣고, 휘지 않아야 하는 상태(09 정지: P2 가 홈에 떨어짐, 00 정지: 키가 홈 안)에서만 교집합 0 을 확인했다. 작동 GIF 는 `frames`(여러 파트를 함께 움직이는 프레임).
- **구멍 많은 다각형 압출**: `trimesh.creation.extrude_polygon` 기본(earcut)은 구멍을 다리로 이어 붙여, 부피는 맞지만 단면·위상에서 구멍이 합쳐진다(앞판 슬롯 44 → 14, QC 얇은 살 38 mm² 오탐). → `tools/efc.extrude_safe`(manifold 삼각분할), selftest '[구멍 많은 판 압출]'.
