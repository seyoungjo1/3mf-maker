# 한국 궁궐(창덕궁 인정전) 모티브 램프 — 스터디 (2026-10-09)

목표: 완전 복제가 아니라 **"한눈에 한국 궁궐"**로 읽히는 램프. 일본 랜턴 샘플(`lantern-sample.md`)의 램프 틀(정방향 지붕·0.8 mm 발광 갓·색별 파트)을 빌리고, 형태 언어는 한국식으로 바꾼다.
색 5가지: 흰색(창호·발광 갓), 갈색(기둥·목부), 초록(단청·공포 띠), 기와색(지붕), 돌 회색(월대·계단).

## 1. 무엇이 "한국 궁궐"로 읽히게 하나 (일본·중국과 갈리는 점)
| 요소 | 한국(인정전) | 일본 랜턴(샘플) | 램프에 쓰는 법 |
|---|---|---|---|
| 지붕 형태 | **팔작지붕**: 긴 변은 처마, 짧은 변 위쪽에 **합각(세모 박공)** + 2단 지붕(중층처럼 보이는 겹지붕) | 사각 보주형 탑 지붕(사방 대칭 원뿔) | 직사각 평면(정면 5칸 : 측면 4칸 ≈ 5:4), 상층 지붕 양 끝에 세로 삼각 합각면 |
| 처마 곡선 | 끝이 **부드럽게** 올라가는 앙곡(118~120° 규칙), 지붕면은 살짝 처짐 | 처마가 거의 직선, 끝만 꺾임 | 처마선 네 모서리 3~4 mm 들림, 지붕면 오목 1~2 mm |
| 공포·단청 | 다포식 공포가 처마 밑에 띠처럼 촘촘, **초록 바탕 단청** | 공포 없음, 단색 | 처마 밑 **초록 계단형 띠**(공포 추상화, 뒤집어 출력) |
| 기둥·벽 | 둥근 **갈색/적갈색 기둥**, 그 사이 **흰 창호(띠살·꽃살문)** | 네모 기둥 + 격자 | 둥근 기둥 Ø8~10, 띠살 창호(세로살 촘촘 + 가로살 3단) |
| 기와 | 회흑색, **용마루·추녀마루 두껍게**, 양 끝 취두·잡상 | 민무늬 | 지붕에 수키와 골(2~3 mm 간격 홈), 마루 3 mm 돌출, 끝 취두 덩어리 ≥ 4 mm |
| 기단 | **2단 월대** + 가운데 계단(답도) + 박석 마당, 난간 없음 | 사다리꼴 받침 | 회색 2단 판 + 정면 계단 2줄(단 2.4 mm = 12층) |
| 현판 | 처마 아래 가운데 현판 | 없음 | 상층 처마 아래 작은 판 (흰/검) — 선택 |

## 2. 램프 구성(파트 = 색) — 초안
```
[8] 상층 지붕 (기와)  팔작 + 용마루·합각            ← 정방향, 처마판 바닥
[7] 상층 공포 띠 (초록) 계단형 띠                      ← 뒤집어 출력
[6] 상층 몸체 (갈색)  기둥 + 창호 틀, 안에 [6w] 흰 갓 0.8 mm
[5] 하층 지붕 (기와)  사방 처마 띠(가운데 뚫림: 상층 통과 + 빛 통로)
[4] 하층 공포 띠 (초록)
[3] 하층 몸체 (갈색)  기둥 5칸×4칸 + 창호, 바닥판에 조명 자리, 안에 [3w] 흰 갓
[2] 월대 (회색)      2단 + 정면 계단, 조명 전선 홈
```
크기 안: 상층 지붕 200×150, 전체 높이 ≈ 175 (월대 18 / 하층 55 / 하층 지붕 24 / 상층 38 / 상층 지붕 40). P1S 256 베드에 파트별로 들어감.
조명: 티라이트(38 Ø) 또는 LED 퍽(70 Ø) — 하층 바닥판 위, 월대 뒤쪽 전선 홈. 상층은 하층 지붕 가운데 구멍으로 빛을 받음.

## 3. 출력 규칙 적용
- 지붕 두 장: 처마판(5 mm) 바닥, 위로 좁아짐(층당 ≤0.115 바깥 돌출 없음). 합각면은 수직. 마루·취두는 위로 자라는 덩어리.
- 공포 띠: 뒤집어 출력(넓은 단이 바닥) → 계단이 안쪽으로 좁아져 오버행 0.
- 창호: 세로살 ≥1.2 mm, 가로살 브리지 ≤ 8 mm. 몸체는 정방향(기둥 수직).
- 발광 갓: 단일 벽 0.8 mm, 직사각 통, 몸체 내벽과 3 mm 여유.
- 끼움: 지붕 안쪽 소켓 ↔ 몸체 상단 0.3 mm/면, 공포 띠는 몸체 위에 얹힘(턱 2 mm).
- 작은 장식(잡상)은 지붕 파트에 붙여 ≥4 mm 덩어리로. 삼각형 파트당 ≤ 200k.

## 4. 결정 필요 (사용자)
1. 조명: 티라이트 / LED 퍽 / Bambu LED Kit 중 무엇에 맞출지(바닥판 지름·전선 홈).
2. 크기: 폭 200 mm(권장) / 160 / 240.
3. AMS 유무: 있으면 창호 흰색을 몸체와 한 파트로(2색 한 플레이트), 없으면 샘플처럼 흰 갓을 따로.
4. 상층 창호도 발광할지(하층 지붕 가운데 뚫림 필요) — 권장 예.
