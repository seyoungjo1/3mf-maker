# 한국 궁궐(창덕궁 인정전) 모티브 램프 — 스터디 (2026-10-09)

목표: 완전 복제가 아니라 **"한눈에 한국 궁궐"**로 읽히는 램프. 일본 랜턴 샘플(`lantern-sample.md`)의 램프 틀(정방향 지붕·0.8 mm 발광 갓·색별 파트)을 빌리고, 형태 언어는 한국식으로 바꾼다.
색 5가지: 흰색(창호·발광 갓), 갈색(기둥·목부), 초록(단청·공포 띠), 기와색(지붕), 돌 회색(월대·계단).

## 1. 무엇이 "한국 궁궐"로 읽히게 하나 (일본·중국과 갈리는 점)
| 요소 | 한국(인정전) | 일본 랜턴(샘플) | 램프에 쓰는 법 |
|---|---|---|---|
| 지붕 형태 | **팔작지붕**: 긴 변은 처마, 짧은 변 위쪽에 **합각(세모 박공)** + 2단 지붕(중층처럼 보이는 겹지붕) | 사각 보주형 탑 지붕(사방 대칭 원뿔) | 직사각 평면(정면 5칸 : 측면 4칸 ≈ 5:4), 상층 지붕 양 끝에 세로 삼각 합각면 |
| 처마 곡선 | 끝이 **부드럽게** 올라가는 앙곡(118~120° 규칙), 지붕면은 살짝 처짐 | 처마가 거의 직선, 끝만 꺾임 | 처마선 네 모서리 3~4 mm 들림, 지붕면 오목 1~2 mm |
| 공포·단청 | 다포식 공포가 처마 밑에 띠처럼 촘촘, **초록 바탕 단청** | 공포 없음, 단색 | 처마 밑 **초록 계단형 띠**(공포 추상화, 뒤집어 출력) |
| 기둥·벽 | 둥근 **갈색/적갈색 기둥**, 그 사이 **흰 창호(띠살·꽃살문)** | 네모 기둥 + 격자 | 둥근 기둥 Ø8~10, 띠살 창호(세로살 촘촘 + 가로살 3단) |
| 기와 | 회흑색, **용마루·추녀마루 두껍게**, 양 끝 취두·잡상 | 민무늬 | 지붕에 수키와 골(2~3 mm 간격 홈), 마루 3 mm 돌출, 끝 취두 덩어리 ≥ 4 mm |
| 기단 | **2단 월대** + 가운데 계단(답도) + 박석 마당, 난간 없음 | 사다리꼴 받침 | 회색 2단 판 + 정면 계단 2줄(단 2.4 mm = 12층) |
| 현판 | 처마 아래 가운데 현판 | 없음 | 상층 처마 아래 작은 판 (흰/검) — 선택 |

## 2. 램프 구성(파트 = 색) — 초안
```
[8] 상층 지붕 (기와)  팔작 + 용마루·합각            ← 정방향, 처마판 바닥
[7] 상층 공포 띠 (초록) 계단형 띠                      ← 뒤집어 출력
[6] 상층 몸체 (갈색)  기둥 + 창호 틀, 안에 [6w] 흰 갓 0.8 mm
[5] 하층 지붕 (기와)  사방 처마 띠(가운데 뚫림: 상층 통과 + 빛 통로)
[4] 하층 공포 띠 (초록)
[3] 하층 몸체 (갈색)  기둥 5칸×4칸 + 창호, 바닥판에 조명 자리, 안에 [3w] 흰 갓
[2] 월대 (회색)      2단 + 정면 계단, 조명 전선 홈
```
크기 안: 상층 지붕 200×150, 전체 높이 ≈ 175 (월대 18 / 하층 55 / 하층 지붕 24 / 상층 38 / 상층 지붕 40). P1S 256 베드에 파트별로 들어감.
조명: 티라이트(38 Ø) 또는 LED 퍽(70 Ø) — 하층 바닥판 위, 월대 뒤쪽 전선 홈. 상층은 하층 지붕 가운데 구멍으로 빛을 받음.

## 3. 출력 규칙 적용
- 지붕 두 장: 처마판(5 mm) 바닥, 위로 좁아짐(층당 ≤0.115 바깥 돌출 없음). 합각면은 수직. 마루·취두는 위로 자라는 덩어리.
- 공포 띠: 뒤집어 출력(넓은 단이 바닥) → 계단이 안쪽으로 좁아져 오버행 0.
- 창호: 세로살 ≥1.2 mm, 가로살 브리지 ≤ 8 mm. 몸체는 정방향(기둥 수직).
- 발광 갓: 단일 벽 0.8 mm, 직사각 통, 몸체 내벽과 3 mm 여유.
- 끼움: 지붕 안쪽 소켓 ↔ 몸체 상단 0.3 mm/면, 공포 띠는 몸체 위에 얹힘(턱 2 mm).
- 작은 장식(잡상)은 지붕 파트에 붙여 ≥4 mm 덩어리로. 삼각형 파트당 ≤ 200k.

## 4. 결정 필요 (사용자)
1. 조명: 티라이트 / LED 퍽 / Bambu LED Kit 중 무엇에 맞출지(바닥판 지름·전선 홈).
2. 크기: 폭 200 mm(권장) / 160 / 240.
3. AMS 유무: 있으면 창호 흰색을 몸체와 한 파트로(2색 한 플레이트), 없으면 샘플처럼 흰 갓을 따로.
4. 상층 창호도 발광할지(하층 지붕 가운데 뚫림 필요) — 권장 예.

## 5. v1 구현 결과 (2026-10-09, `작업중/changdeok-lamp/`)
사용자 결정: 조명 **Bambu LED Lamp Kit 001**(Ø59×18 퍽, 1.5 m 선·인라인 스위치), 폭 **160**, 상층 창호도 발광, 느낌은 종이모형 사진(2층 팔작·흰 처마선·초록 공포 띠·띠살 창·2단 월대 계단). DWG 4장은 이 환경에서 변환 불가(libredwg·ODA 없음) → 점군 스캔 실루엣 px 비례만 썼다.
- 크기 160×138×138, 11 파트 5색, 플레이트 2장. 비례(정면) 하층 처마 140 : 상층 처마 128 : 용마루 85 : 하층 몸체 103 : 월대 160.
- **몸체 단면 규칙(o = 바깥면에서 안쪽)**: 기둥 Ø6 중심 3 / 문지방 0–5 / 창살 깊이 2–5 / 인방 사다리꼴 아래 2–5 → 위 0–6.3(높이 6) / 테두리 3–5.7 / 띠 안쪽 벽 2.7 / 지붕 홈 2.7–6.0 / 개구는 홈 안쪽 섬 벽 2 안쪽. 이렇게 해야 모든 링이 아래 부재 위에 완전히 올라앉는다(v0 는 인방이 창살 밖으로 2.1 mm 떠서 한 층 캔틸레버 635 mm²).
- 창살: 칸 가운데 멀리언 1.6, 반쪽마다 틈 ≈ 2 mm 로 세로살 균등 배치, 가로살 2단은 기둥 안으로 0.8 들어가게(접선 틈 제거). 브리지 2.6~2.8.
- 지붕: 처마판 4 + 볼록 껍질(하층 사다리꼴, 상층 팔작 = 처마 직사각 + 합각 직사각(z+14) + 용마루 선(z+32)). 용마루·취두는 `sink = 폭×경사/2 + 0.3` 만큼 가라앉혀 오버행 0. 흰 처마 띠는 지붕 오브젝트의 두 번째 파트.
- 하층 지붕 윗면을 상층 밑판보다 3 mm 크게(101×67) 하고 **바깥 턱**(1.6×1.8)으로 밑판을 잡는다 — 밑판 밑면 포켓(v0)은 0.5 mm 스커트 얇은 살·2.8 브리지를 만들었다.
- LED: 월대 윗면 포켓 Ø60(바닥 3.5) + 전선 터널 6×5 뒤로, 하층 바닥판(Ø50 구멍)이 덮음. 2단 월대 앞 들여쓰기 14(계단 5×2.4 자리).
- QC: 한쪽 지지 오버행 0, 브리지 ≤ 6.0, 조립 교집합 0, 끼움 0.3, lib3mf 0 경고. 무게 통짜 957 g → 인필 15 % 추정 334 g. 무게중심 z 52, 넘어지는 각 50°/57°.
- 남은 것(v2): 앙곡·합각 널·기와 골·추녀마루·현판·난간석. 사용자 출력 피드백 후.


## 6. v2 실측 교훈 — 참고 자료를 "전부" 읽는 법 (2026-10-10)
사용자 지적: "사진이랑만 대조하냐, 옆면 도면·3D 모델도 줬다." 정면 스캔 하나만 맞추고 측면 도면·SKP 를 안 본 결과 측면 비례가 통째로 틀렸다.
- **DWG 치수선은 줄마다 대상이 다르다.** 측면도에 치수 줄이 둘: 위 줄 15,405.8(3,295.8/4,456.5/4,617.1/3,036.4) = **상층** 기둥, 아래 줄 18,344.4(4,591.7/4,587.8/4,580.7/4,584.2) = **하층** 기둥. 정면도도 위 줄(1,536.3 들여쓰기 + 상층 5칸) / 아래 줄(하층 24,449). 평면도 치수는 하층 정면 + 상층 측면이 섞여 있었다 → 그걸 하층 측면으로 읽어 102.7 mm(실제 122.3), 평면 고주 2칸(9.17 m)을 상층 측면으로 읽어 61.1 mm(실제 102.7). **치수선 y 위치(어느 높이에 그렸는지)와 스캔 위 기둥을 겹쳐 확인한 뒤 쓴다.** (`ezdxf` DIMENSION defpoint2/3 와 IMAGE 삽입점으로 정합)
- 정합 검사: 측면 스캔에서 수평 치수(448 px = 15,406)와 수직 치수(617 px = 21,181)가 같은 34.3 mm/px 로 맞으면 정사영·정합이 맞다. 평면 스캔은 위에서 본 **원근** 영상(지붕이 기둥보다 크게 찍힘) → 절대 치수로 쓰지 말고 같은 높이 선(처마선)의 **비율**만 쓴다.
- 결과: 측면 처마 끝 스캔 −93.2/92.6 vs 모델 −93.4/93.1, 상층 −85.0/83.9 vs −85.7/85.3 (mm). 정면은 기존대로 0.6 이내.
- **안허리곡(평면 처마 U)**: 평면 스캔 앞변에서 변 가운데→모서리 들어간 양 = 반길이의 4.4 %, 모양 ∝ t^2.7 (t = 가운데 0 → 모서리 1, 7점 맞춤 평균 오차 0.059). t⁴ 로 하면 가운데 70 % 가 직선으로 보인다("전부 직선" 지적). 모서리 위치(입면 정합점)는 고정하고 변 가운데를 들인다.
- **용마루 휨**: 정면 스캔 가운데 141.0 → |x|=56 mm 에서 143.2 → 2.2·(x/56)². 흰 양성은 밑면 평평·윗면만 휜 판(눕혀 출력, 접지 919 mm²).
- **SKP 는 인정전이 아니라 창경궁**(`sample/changgyeonggung_sketchup.skp`, 업로드 이름 `___.skp` = 한글 세 글자). 처음에 인정전으로 잘못 붙여 "평면비 1.07 vs DWG 1.59 라 비례를 못 쓴다"고 적었는데, 다른 건물이라 비례가 다른 것이 당연하다 — **파일 이름·건물 이름은 사용자에게 확인**하고, 비례는 인정전 DWG 로만 잡는다. zip 안 `model.dat`(SketchUp 2021+ 태그 형식)는 공개 리더가 없어 정점만 추출해 단면·평면 점그림으로 읽었다. 창경궁 처마밑(사용자: "한옥 처마밑이 어떻게 됐는지 상상이 안 되니 SKP 를 참고하라"): ① 둥근 서까래 마구리 한 줄(지름/피치 0.94, 변에서는 수평) ② 그 위 기와 끝 ∩ 줄 같은 피치 ③ **모서리로 갈수록 두 줄 모두 들림**(앙곡) ④ 평면에서 모서리 서까래가 벽 모서리에서 부채꼴로 퍼짐(선자연, 대각선을 따라 약 7개) ⑤ 맨 끝 세로 추녀. 램프 적용: 피치 2.8·마구리 Ø2.2·막새 Ø2.0, 모서리 부채꼴 홈, 추녀 끝 각재(폭 3, 대각 1.8 돌출), 처마선 들림 3.0(아래).
- 뒤집어 출력하는 처마밑의 돌출 마구리는 윗면(조립 기준)을 경사로: 노출 깊이 1.0 / 높이 1.8 → 층당 0.111.
- 평방 링 밑면 홈이 링 안쪽 끝까지 파이면 홈 천장이 한쪽 지지 선반(1,997 mm²)이 된다 → 안쪽 턱 1.2 를 남겨 양쪽 지지 브리지(5.3)로.
- 휜 경로를 따르는 막대(추녀마루)는 눕힐 면을 한 평면으로 만든다(단면 −u 쪽 점을 u·p = 최소값 평면에 투영) → 접지 0~72 → 133~146 mm².
- 다른 한옥 예시: `sample/hanok_MAINBUILDING_sketchup.skp` — 부품 썸네일에 휜 원형 서까래(Group#113~118)·처마 쐐기 각재(Component#86~88·64·99)·굵은 모서리 각재(#140·145)가 보인다(미실측).
- **처마선 들림과 평평한 출력면을 함께 만족시키는 분할**: 처마밑(뒤집어 출력)의 윗면=베드라 평평해야 하고, 흰 테·기와도 밑면 출력 → 맞닿는 면을 평면으로 묶으면 처마선이 수평이 되어 모서리 기와만 떠 보인다("기와 모퉁이 끝이 떠있다"). 해법(사용자 선택): 처마밑 윗면 평평 + **모서리 갈색 쐐기 4개**(평평하게 출력, 두께 0.3→3.0) + 흰 테는 평평하게 출력해 끼우면 쐐기를 따라 휨(1.0 mm, 변형률 ≈0.25 %) + 기와 처마 띠 밑면을 같은 들림 함수로 올림(안 보이는 면 서포트). 들림 = 3.0·f(|x|/hx)·f(|y|/hy), f(t)=((t−0.55)/0.45)² (스캔: 끝선 u=−69 → 끝 +3).
