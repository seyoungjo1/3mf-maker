# 자석 걸이대 (75TR3DQ 펜·에어마우스 걸이, 2026-10-10) — `작업중/tv-pen-hanger/`

## 자석 고정력 — `python tools/mm.py magnet`
- 모델: 축 자화 원판(면전하 σ = Br/μ0) + 두꺼운 철판 = 거울상 자석(간격 2g). 네 면 쌍의 동축 링-링 힘을 타원 적분으로 적분(`tools/magnet.py`). 먼 거리에서 쌍극자-거울상 식과 1.2 % 안(selftest).
- Ø20×1 N35(Br 1.17) 이상 상한: 간격 0 → 13.4 N, 0.1 → 10.5, 0.5 → 5.5, 1.0 → 3.4, 2.0 → 1.8 N. **얇은 자석은 간격에 매우 민감** — 0.5 mm 만 떠도 절반.
- 설계값 = 상한 × 0.5(도장·니켈·얇은 판·거칠기). 수직 벽에 거는 물건은 **떼어짐보다 미끄러짐이 먼저**: 미끄러짐 용량 = μ(≈0.3) × 흡착력 합. 떼어짐은 피벗(아래 모서리)~자석 거리가 길면 여유가 크다.
- 그래서 자석 포켓은 **뒷면에 열고 접착**(앞면 0.1 들어감). 0.6~0.8 mm 살 뒤에 묻으면(일시정지 삽입) 흡착력이 40 % 로 떨어져 3개로는 모자란다.
- 상대가 자석이면 극 방향을 맞춰야 한다 — 접착 전 붙는 면 표시.

## 형상·출력
- 단면이 일정한 걸이(뒷판 + U 홈)는 **옆으로 눕혀 단면을 베드에** — 벽 전부 수직, 서포트 0, 홈이 층과 평행한 평면에서 휜다.
- 그 방향에서 뒷면 포켓은 수평 원 구멍이 되므로 **출력 위쪽으로 28° 눈물방울**(tan28°×0.2 = 0.106/층). 끝(+r/sin28° = 21.5)이 다음 포켓·윗면과 겹치지 않게 간격 36, 첫 중심 14.

## 도구 실패 기록
1. 단면을 통째로 `extrude_polygon` 하면 옆면 삼각형이 110 mm 길이 하나 → QC 레이 검사(wall_steps)의 후보 삼각형이 폭증해 메모리 초과(종료 137). **긴 압출은 `sweep_polygon` 으로 2 mm 마디**를 두고, 원 분할은 4분원당 16(R 9 에서 현 처짐 0.01)으로.
2. `pipeline.gaps` 가 정점 KD-트리 거리 5 mm 로 먼저 거르면서, 정점이 듬성한 메시(12면 상자)는 실제 0.1 간격을 12.75 로 냈다 → 면 5000 개 이하 메시는 전부 정확히 잰다(selftest '듬성한 메시 간격').
3. `mm section` 제목·범례의 한글이 □ 로 나옴 → WenQuanYi Zen Hei 대체 글꼴 지정.
