# 디테일한 도면(모델)을 짜는 방법 — 스터디 (2026-10-09)

사용자 지적: "샘플(종이모형) 디테일의 10 %도 안 된다. 하나하나 상자를 코드로 쌓으니 그렇다. 도면을 짜는 법을 먼저 스터디하라."
이 문서는 **특정 건물이 아니라 '디테일을 내는 설계 방법'** 을 정리한 것이다. `design-method.md`(치수·방향·공차·기구 일반)를 전제로, 그 위에 **장식·반복 부재가 많은 모델**을 짜는 절차를 더한다.

## 0. 결론 — 디테일 설계 10원칙
1. **디테일 = 작은 부재의 반복**이다. 덩어리(매싱)에 장식을 새기는 것이 아니라, 부재 하나를 정확히 만들고 배열한다. 종이모형 42부품, 서울대 1:100 근정전 레이저컷 3,537부재가 그 증거다 — 부재 수가 곧 디테일이다.
2. 모델링 전에 **요소 목록(BOM)** 을 적는다. 참고 사진·도면에서 보이는 요소를 전부(보통 20~40개) 나열하고, 요소마다 실제 크기 → 모형 크기 → 표현 방법(입체 부재 / 부조 / 색 / 생략)을 정한다. 이것이 **LOD(표현 수준) 예산**이다.
3. **스케일은 '보여야 할 가장 작은 요소'가 0.8 mm 이상**이 되게 정한다. 안 되면 그 요소를 **과장**한다(종이모형도 공포·서까래를 실제 비례보다 키운다).
4. 모든 부재는 **보이는 면이 윗면(또는 바닥면)이 되게 눕혀** 찍고 조립한다. XY 해상도(선 0.4)가 Z(층 0.2·계단)보다 곱고, 윗면에만 깨끗한 부조가 나온다.
5. **색 경계 = 파트 경계**. 한 오브젝트 안의 색 파트(열쇠고리 방식, 파트별 extruder)로 두면 접착 없이 다색이 된다. 평판은 "바탕 0.6 + 무늬 0.6" 2색 인레이.
6. **2D 프로파일 + 경로**(압출·스윕·로프트·배열)로 만든다. 상자 유니온으로는 곡선·단면·반복이 나오지 않는다.
7. **조인트는 표준 하나**(홈 = 혀 + 0.6, 깊이 2~3, 턱으로 위치)로 통일하고, 쿠폰으로 먼저 확정한다.
8. **오버레이 검사**: 참고 사진과 같은 시점·화각으로 렌더해 반투명으로 겹친다. "느낌 차이"는 요소 유무·비례 차이로 숫자가 된다.
9. **요소 달성률**을 보고한다: 구현 요소 수 / 목록 요소 수. (창덕궁 램프 v1 = 5/22 ≈ 23 %, 체감 10 %.)
10. 작은 부재는 **띠(strip)·판(panel)으로 묶어** 한 파트로 찍는다(분실·<5 mm 금지 규칙 유지). 몸체는 부재를 받는 뼈대일 뿐이며, 부재 자리(홈·턱)를 미리 판다.

## 1. 샘플(종이모형·레이저컷 키트)이 디테일을 내는 원리
| 원리 | 종이/레이저컷 키트 | FDM 로 옮기면 |
|---|---|---|
| 얇은 2D 판의 적층 | 모든 부품이 1~2 mm 판, 실루엣으로 형태 | 평판 파트(두께 1.2~2) 눕혀 출력, 끼움 홈에 세움 |
| 반복 단위 | 공포 1단위·서까래 1개·난간 1칸이 같은 부품 n개 | 부재 함수 1개 × 배열 |
| 색은 인쇄 | 단청·창살·기와 무늬가 인쇄된 면 | AMS 2색 평판(바탕+무늬), 색 띠로 추상화 |
| 과장 | 공포 띠를 몸체 높이의 ≈40 %, 지붕을 전체의 ≈60 % | 사진 측정값으로 비례를 잡되 작은 요소는 1.5~2배 키움 |
| 조립 | 탭·슬롯, 접착 | 홈·혀 0.3, 턱, 필요한 곳만 순간접착 |
사진(사용자 종이모형, 640 px) 측정: 하층 몸체 57 px, 공포 띠 23 px, 하층 지붕 60 px, 상층 지붕(합각 포함) 115 px, 상층 처마 폭/하층 처마 폭 0.64, 몸체 폭/하층 처마 폭 0.77.

## 2. 요소 목록(BOM)과 LOD 예산 짜는 법
표 양식(프로젝트 README 에 둔다):
`요소 | 실제 치수 | 스케일 치수 | 최소치 통과? | 방법(입체/부조/색/생략) | 색·파트 | 출력 방향 | 결합`
- 스케일별 통념(모형 제작사 지침): 1:200 — 창은 개구·색, 난간은 띠; 1:100 — 창틀·난간 형태; 1:50 — 창살·기와 개별. 폭 160 mm 램프는 1:200급 크기인데 1:50급 느낌을 원하므로 **과장 + 부조 + 색**으로 메운다.
- **FDM 최소치(0.4 노즐, 출처 §11)**: 부조 폭 ≥ 1.0(취리히대 지침), 권장 1.2(멜버른대 팹랩), 폭은 0.4 의 배수, 핀 ≥ 1.0(짧게), 기둥 2~3. 이 저장소 규칙: **선·살 0.8(두 줄), 돌출 높이 0.6(3층), 틈 0.6, 세워진 살 1.2, 법수·작은 기둥 2.0**. 0.2 노즐이면 0.5/0.4(속도 4~5배 느림, Arachne 켬).
- 요소가 최소치 아래면 선택지는 셋뿐: 과장 / 부조·색으로 대체 / 생략. "작게 그냥 넣기"는 없다(뭉개지거나 떨어진다).

## 3. 부재 라이브러리(component library)로 짜는 법
- 부재마다 **매개변수 함수 1개**: 치수표 → 2D 프로파일(shapely) → 생성(압출/스윕/로프트) → 자기 자리 좌표계(바닥 z=0, 붙는 면 y=0). 예: 공포 단위(폭·단수·돌출), 서까래 빗(피치·지름·깊이), 기와 줄(피치·폭·높이·막새), 창살 판(살 폭·피치·테두리·바탕), 난간 칸(법수·동자·구멍), 마루(폭·높이·끝 장식), 잡상(≥ 4 mm 덩어리).
- **배열 함수 1개**: 선형(피치·개수·여백 자동), 모서리 미러/회전, 경로 따라(처마 곡선) 위치+자세. 부재 수백 개가 코드 몇 줄이다.
- 몸체는 뼈대: 부재가 끼워질 홈·턱·포켓을 뼈대에 먼저 판다(뼈대가 곧 조립도).
- 디테일 ∝ (부재 종류 × 인스턴스 수). v1 은 부재 종류 0, 파트 11. 종이모형 수준은 부재 종류 8~12, 인스턴스 수백.

## 4. 곡선·단면 — 프로파일과 스윕
- 처마 곡선(앙곡·안허리곡): 양 끝 들림을 베지어/원호로 정의하고, 처마판·서까래·막새 배열이 **그 경로를 따라** 간다. 층당 0.115 규칙은 경로의 기울기(dz/dx)로 바로 검사.
- 기와: 단면(암키와 오목 + 수키와 볼록) 프로파일을 경사면 방향으로 스윕 → 지붕 면 패턴. 마루: 단면 스윕 + 끝 장식 덩어리.
- 기둥·보: 원/사각 압출, 민흘림(테이퍼)은 로프트.
- 도구: shapely + trimesh(`extrude_polygon`, `sweep_polygon`, 볼록 껍질 로프트, manifold 불리언) / build123d·CadQuery(스케치→스윕·로프트·필렛·패턴, 이 환경엔 미설치) / **Blender**(커브+배열·커브 모디파이어, 지오메트리 노드 — 연결되면 1순위, 기와·처마 생성기 애드온 존재) / OpenSCAD.

## 5. 색·파트 분할 설계
- 색 경계가 파트 경계. 같은 오브젝트의 파트로 넣어 extruder 지정(`generic3mf.py`, `material_order`로 플레이트 간 번호 고정).
- 평판 2색: 바탕 0.6 + 무늬 0.6, 눕혀서. 세워진 벽에서 색을 나누면 각 색 두께 ≥ 0.8.
- 단청·무늬는 색 띠 + 점/선 패턴(≥ 0.8)으로 추상화. 플레이트당 색 ≤ 4(AMS 1대) → 색 조합으로 플레이트를 나눈다.
- 다색 파트가 면접촉하면 첫 층 EFC 선반영은 `pre_expand_first_layer_group` 으로 바깥 윤곽만.

## 6. 결합(조립) 설계
- 표준 조인트: 홈 폭 = 혀 두께 + 0.6(0.3/면), 깊이 2~3, 턱 1.5~2 로 위치, 접착 없이 끼움. 눕혀 찍은 판은 뼈대 안쪽 홈에 슬라이드.
- 끼움 쿠폰(0.2/0.3/0.4) → 값 확정 → 전 부재에 같은 값.
- 작은 부재는 띠로 묶거나 뼈대와 한 몸으로(뒤집어 찍는 공포 띠처럼) — 떨어지는 부품 없음.

## 7. 비교·검증
- **오버레이**: 참고 사진의 카메라(시점·화각)를 맞춘 렌더를 반투명으로 겹친다(`render_preview.py` 에 카메라 지정 옵션 추가 예정). 요소 유무·비례 차이를 표로.
- **요소 체크리스트**: BOM 각 행 O/X → 달성률. 70 % 아래면 "느낌이 안 난다".
- QC: 기존 규칙 + 디테일 파트는 `--min-wall 0.8`.

## 8. 실측 도면이 있을 때 읽는 법
- DWG → DXF: libredwg `dwg2dxf`(소스 빌드 0.13.3, 이 환경에서 성공; apt·pip 패키지 없음) → `ezdxf` 로 레이어·DIMENSION(측정값·위치)·IMAGE(삽입점·mm/px) 추출.
- 입면이 래스터(IMAGE)인 도면은 벡터가 치수선뿐이다 → **치수선을 정사영상에 정합**(삽입점+mm/px)하면 영상 위에서 요소별 mm 를 읽을 수 있다. 측정 한계 = 영상 해상도(2000 px 폭이면 ≈26 mm/px).
- 치수는 "기준선(월대 윗면 등) + 누적 높이", "기둥 중심 간격", "들여쓰기"로 읽고 표로 옮긴다. 추정값은 반드시 '측정'과 구분해 적는다.

## 10. 디테일 설계 시작 전 체크리스트
1) 요소 목록 20개 이상 2) 스케일·최소치 결정(과장 목록 포함) 3) 부재 종류 ≥ 8 정의(각각 치수표) 4) 배열 계획(피치·개수·모서리) 5) 색/파트 분할표(플레이트당 ≤ 4색) 6) 표준 조인트·쿠폰 7) 뼈대에 부재 자리 8) 오버레이 비교 9) QC·요소 달성률 보고.
**사용자 검사**: 이 체크리스트의 1)~5) 표를 먼저 보여 승인받은 뒤 모델링한다.
