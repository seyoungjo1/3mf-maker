## 출력 방향에서 정리한 것
- 보이는 면(글자·테두리 챔퍼)은 **윗면으로 눕혀** 찍어야 컷 경사면이 매끈하다. 판을 30° 기울인 채 한 몸으로 찍으면 앞면이 층 계단(0.2/ tan30° ≈ 0.35 mm 단)으로 덮인다 → 판은 평평하게, 기울기는 받침이 만든다.
- 돌출 요소 윗모서리 챔퍼는 위로 좁아지므로 오버행 0. 챔퍼 폭은 노즐 2줄(0.8) 이상이어야 빛이 보인다.
- 다색(바탕 vs 은색 돌출)은 높이로 나뉘므로 단색 출력 + 색 바꿈(층 높이에서 필라멘트 교체)으로도 된다 — AMS 없이 가능.

## 사용자 결정·배운 것 (v1 시안, `작업중/genesis-parking-plate/`)
- 사용자 스케치 `sample/parking_plate_user_sketch_inlay.jpg`: 바닥에서 30° 정도 기운 **쐐기 몸통**(뒤 수직·앞 아래 둥근 코)의 비탈면에 **깊게 판 홈**, 다른 색 조각을 앞에서 끼움. 색이 다른 부분은 따로 출력.
- 비탈면에 **면 수직** 홈을 파면 홈 뒷벽이 층당 0.2·tan θ 의 오버행이 된다 → θ = 30° 는 0.1155(규칙 0.115 초과), **28° = 0.106** 으로.
- 0·8 속 섬: 홈을 글자 모양(고리)으로만 파면 섬은 몸통의 일부로 남는다(섬 조각을 따로 만들면 5 mm·50 mm³ 규칙 위반).
- 글자 윗모서리 챔퍼(다이아몬드 컷)는 build123d `chamfer` 가 InterDisplay Black '8' 바깥 윤곽에서 실패 → 윤곽을 주기 스플라인 120점으로 다시 그리면 된다(나머지 글자는 원본 곡선 그대로).
- 비탈면 홈의 아랫벽 앞 모서리는 수평 단면에서 폭이 0 으로 줄어 QC '얇은 살'로 잡힌다(183.9 mm², 테두리 167 mm 길이) — 비탈 윗면 모서리라 정상, 근거와 함께 허용.
- 글자 조각은 바닥 접지 57~99 mm²(높이 4.2) — 100 mm² 규칙 미달이지만 납작해 넘어지지 않아 허용(떨어지면 브림).

## v2 — 판 통째로 끼우기 (사용자: "스케치는 예시, 음각 말고 판 자체를 끼우게 — 컬러 프린팅 레이어 때문")
- 판을 평평하게 앞면 위로 2색 출력: 검정 바탕 z 0~3.0, 은색(테두리 띠·글자·로고)은 **전부 z 3.0 에서 시작** → 층 기준 색 바꿈 1회(AMS 없어도 일시정지 교체로 됨). 받침(쐐기)은 단색, 비탈면에 판 모양 홈(깊이 = 판 바탕 3.0, 여유 0.25/쪽) — 바탕 윗면이 받침 면과 같은 높이, 은색만 1.2 위로.
- **색 파트를 따로 QC 하면 안 된다**: 은색 파트만 보면 QC 가 z 3.0 을 바닥으로 여기고 EFC 0.15 를 깎아 1→2층 단차를 가짜 오버행(3,029 mm²)으로 잡는다. 출력 QC 는 실제로 찍히는 덩어리(바탕 ∪ 은색)로, 조립 검증·렌더는 색 파트 그대로.
- 낱개 음각(v1)보다 나은 점: 조각 15개 → 판 1장, 접지 미달·얇은 살 허용 0, 비탈 계단 줄이 보이는 곳은 받침 테두리 3 mm 뿐.
