# 3MF 결과물의 인스타그램 게시 스터디

2026-10-21 사용자 결정: `3mf-maker` 안 별도 브랜치에서 GitHub Actions + Instagram 공식 API를 준비한다. 주 소재는 3MF 캡처 결과물이며 **게시글 품질도 함께 신경 쓴다**.

## 적용할 방법

- 계정 연결과 게시: [운영 문서](../../../../../docs/social/instagram-publishing.md).
- 이미지 선택과 글: [편집 지침](../../../../../docs/social/editorial-guide.md).
- 개발 브랜치: `codex/instagram-publishing`. main 병합과 실제 게시/예약 활성화는 현재 범위에 포함하지 않는다.
- 프로젝트 README·REPORT·렌더·실출력 기록에서 소재를 수집한다. 검증된 모델 결과를 쓰되 캡션용으로 미검증 모델을 새로 만들지 않는다.
- 렌더/슬라이서 캡처와 실출력 사진을 구분하고, 실제 출력 전에는 완료·출력 성공을 주장하지 않는다.
- GIF는 피드 이미지로 바로 보내지 않고 필요한 경우 MP4 릴스로 변환·검증한다. 먼저 단일 이미지 게시부터 연결한다.
- 주차번호판 등은 숫자·이름이 캡처에도 남을 수 있다. 공개용 더미 데이터로 만든 캡처를 선택한다. 비공개 폴더 제외 설정만으로 이미지 개인정보가 가려지는 것은 아니다.

## 조사 한계

Meta 직접 문서 일부가 429/접근 제한이라 공식 Postman 자료와 GitHub 공식 문서로 구조를 확인했다. 출처는 운영 문서에 기록했다. 최신 API 버전, 앱 접근 등급, 정확한 미디어 한도와 토큰 조건은 계정 설정 때 재확인한다. 현재 계정 연결과 실제 게시 테스트는 수행하지 않았다.
