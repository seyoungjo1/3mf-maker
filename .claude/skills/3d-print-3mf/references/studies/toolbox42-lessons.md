# Toolbox42 에서 배운 것 (v4~v6, 2026-10)
1. 오버행 규칙은 **출력물** 기준 — 코끼리발 보정 0.15가 첫 층을 깎아 1→2층이 0.265가 됐고, 허공에 쌓인 2층이 눌려 외곽이 들떴다. 본체 바닥(0.18/층)도 규칙 밖.
2. 기준 파트가 규칙 밖이면 복제하지 않는다. "같게"보다 "규칙 안에서 같아 보이게"(샘플처럼 45° 챔퍼).
3. 멀티컬러 플레이트의 첫 층은 식은 상태에서 쌓인다 → 첫 5층 오버행 0.
4. 걸쇠는 링만 닿아(7 mm²) 오그라들었다 → 바닥 전면 접지(775 mm²).
5. 손잡이 다리 2.7 mm → 처짐 1.07 mm·응력 23 MPa, 5.4 mm → 0.13 mm.
6. ~~ChatGPT 원본의 걸쇠는 본체 귀와 치수가 맞지 않았다~~ → **오판**. 걸쇠 폭 숫자만 비교하고 실제로 놓아 보지 않은 채 "안 맞는다"고 적었다. 사용자 출력본에서는 v5 걸쇠가 본체 귀에 볼트로 결합돼 스냅으로 잘 잠긴다(2026-10-09 사진). 결합부는 반드시 메시를 실제 좌표에 놓고 교집합·간격으로 판정하고, 작동 GIF 로 눈으로 확인한다.
7. Bambu 프로젝트 3MF는 손으로 지은 설정으로는 열리지 않는다 → 일반 3MF(mm3mf 방식) + 샘플 유도 설정.
8. 추측으로 원인을 말하지 않는다(팬 OFF 말림 → 철회). 수치로 보여주고, 모르면 모른다고 한다.
9. 사용자가 올린 명판 3MF 를 치수(50×30×7)만 읽고 형상(R10 모서리·테두리 띠)을 안 본 채 넣는 방향을 추측했다 → 샘플은 단면 그림을 먼저 보여주고, 그림에서 읽히는 사실만 말한다(`nameplate-sample.md`).
