# Toolbox42 에서 배운 것 (v4~v6, 2026-10)
1. 오버행 규칙은 **출력물** 기준 — 코끼리발 보정 0.15가 첫 층을 깎아 1→2층이 0.265가 됐고, 허공에 쌓인 2층이 눌려 외곽이 들떴다. 본체 바닥(0.18/층)도 규칙 밖.
2. 기준 파트가 규칙 밖이면 복제하지 않는다. "같게"보다 "규칙 안에서 같아 보이게"(샘플처럼 45° 챔퍼).
3. 멀티컬러 플레이트의 첫 층은 식은 상태에서 쌓인다 → 첫 5층 오버행 0.
4. 걸쇠는 링만 닿아(7 mm²) 오그라들었다 → 바닥 전면 접지(775 mm²).
5. 손잡이 다리 2.7 mm → 처짐 1.07 mm·응력 23 MPa, 5.4 mm → 0.13 mm.
6. ~~ChatGPT 원본의 걸쇠는 본체 귀와 치수가 맞지 않았다~~ → **오판**. 걸쇠 폭 숫자와 미확정 조립 가정만으로 “안 맞는다”고 단정했다. 사용자 출력본에서는 v5 걸쇠가 본체 귀에 볼트로 결합돼 스냅으로 잘 잠긴다(2026-10-09 사진·사용자 재확인). 결합부는 메시를 실제 좌표에 놓고 교집합·간격·작동 GIF로 판정한다. 검증되지 않은 캔틸레버 계산값을 실물 작동 힘으로 단정하지 않는다.
7. Bambu 프로젝트 3MF는 손으로 지은 설정으로는 열리지 않는다 → 일반 3MF(mm3mf 방식) + 샘플 유도 설정.
8. 추측으로 원인을 말하지 않는다(팬 OFF 말림 → 철회). 수치로 보여주고, 모르면 모른다고 한다.
9. 사용자가 올린 명판 3MF 를 치수(50×30×7)만 읽고 형상(R10 모서리·테두리 띠)을 안 본 채 넣는 방향을 추측했다 → 샘플은 단면 그림을 먼저 보여주고, 그림에서 읽히는 사실만 말한다(`nameplate-sample.md`).
10. (v7, 48장) 파이프라인이 첫 실행에서 잡은 것 셋: 뒷칸 깊이 오측(51.8 → 실제 50.0, 칸막이 3.0)으로 첫 명판이 칸막이에 0.8 겹침 / 경첩 회전 부호 반대(+각도가 본체 속으로) / EFC 로 키운 첫 층을 조립 검사에 넣어 생긴 0.1 mm³ 가짜 간섭. **치수는 레이로 직접 재고, 회전은 스윕 결과(z 범위)로 방향을 확인하고, 조립 검사는 공칭 형상으로** 한다.
11. 립 두께를 단면 그림에서 2.3 으로 읽었지만 레이 실측은 1.6 — 그림으로 읽은 치수는 치수가 아니다. 끼움면이 어느 면인지(스커트 안쪽면 ↔ 립 바깥면 0.20) 닫힘 상태에서 레이로 확인한 뒤 그 면만 깎는다.
12. 도구 실패 기록: `signed_distance`(contains 레이) 와 먼 점의 `closest_point` 는 메모리 폭주(2천만 배열) → KD-트리 정점 거리로 거른 뒤 가까운 점만 정확히; 48장 명판 한 메시의 manifold 교집합은 조각별로; `ulimit -v` 아래서는 Chromium 이 뜨지 않는다; `nohup … &` 는 셸 종료와 함께 죽는다(run_in_background 사용).
13. (v8) 코끼리발·냉각 대책을 형상에 그대로 드러내면 안 된다. v6 뚜껑의 "0.8 mm 전체 윤곽 수직 띠"는 윗면 둘레에 1.58 mm 턱(접시 테두리)을 만들었고 사용자가 성의 없는 디자인으로 반려했다. 대책은 보이지 않게(EFC 선반영, 띠는 곡선 시작 자리에 0.6 mm) 넣고, 겉모습은 본체와 같은 연속 곡선으로 유지한다. **시간이 걸려도 형상 품질을 타협하지 않는다.**
14. (v9) **출력물 옆면의 줄은 프린터 흔들림이 아니라 설계였다.** v6·v8 뚜껑 모서리 스크립트가 곡선 로프트는 z 7.8 까지, 잘라낼 띠는 z 7.9 까지 잡아 스커트 벽 둘레에 0.1 mm 수평 틈을 팠다 → 슬라이서가 틈 위아래를 윗면/아랫면으로 처리해 줄이 생김. v7·v8 본체 바닥은 0.1 mm 판을 쌓아 0.057 mm 계단. 대책: QC 에 **벽 속 수평 틈 검사**(z 레이, 같은 높이 10개 이상) 추가, 잘라낼 영역은 항상 로프트 안에 들어가게, 곡면은 `tools/loft.py` 링 로프트로(판 쌓기 금지). 렌더에 보이는 줄은 실제 출력에도 나온다 — 렌더의 줄은 무시하지 말고 원인을 찾는다.
15. 로고 메시를 그대로 불리언에 넣으면 글자 속 구멍 껍질 때문에 실패할 수 있다(15조각·겹침 112 mm³). 평판 인레이는 단면 폴리곤(z 중간)을 받아 인레이와 포켓을 **같은 폴리곤으로** 압출한다 — 정확히 맞물리고 크기 변경(1.5배)도 2D 에서.
16. (v10) 몸통 모서리에 새 곡선을 입히면서 외곽 밖 돌출부(걸쇠 탭 기둥·경첩 귀 받침)만 원형으로 남기면, 둘 사이에 V자 홈이 생긴다(탭 x=435 y 197~199 z 0~5, 상부 렌더의 짧은 줄). 돌출부가 선 폭만큼은 벽 안쪽 띠까지 원형을 남긴다(`tools/edge.py lump_zones`). 그러면 경계가 돌출부 옆면이 되어 매끈한 벽에 이음매가 없다. 확인은 돌출부마다 원본과 겹친 단면(`mm.py section`).
17. 원본 벽이 각진 다각형 모서리면 해석 원호(R 6.75)와 최대 0.1 mm 어긋나, 원본 벽과 새 곡면이 만나는 높이에 턱이 생긴다(z 7.08 네 모서리) → 몸통 외곽은 원본 벽 다각형을 그대로 쓴다(`fit_rounded_rect` 의 실제 외곽).
18. 이미 출력한 부품과의 호환은 말로 하지 않고 바꿔 끼워 검증한다: `python tools/mm.py assemble <config> --override '{"base":"v8parts_nominal.pkl:base"}'` (v8 하판 + v10 뚜껑: 간섭 0, 립 0.30, 경첩·손잡이 스윕 간섭 0).
