# 도면을 어떻게 짜면 좋은가 — 설계 방법론 (2026-10 스터디)

프린터 P1S(0.4 노즐, 0.2 층), PLA 기준. 출처는 `../sources.md`와 본문 링크.

## 1. 순서 (이 순서를 지키면 대부분의 실패가 사라진다)
1. **용도·힘·조립을 먼저 적는다**: 어디에 힘이 걸리는지(들기·누르기·비틀기), 무엇과 결합하는지(핀·나사·끼움·스냅), 몇 번 열고 닫는지.
2. **출력 방향을 먼저 정한다**: 가장 큰 평면이 바닥, 힘이 층과 평행(Z 적층 방향은 강도 ½). 방향이 정해져야 어느 면이 보이고 어느 면이 오버행인지 정해진다.
3. **결합 치수를 상대 파트에서 측정**해 표로 적는다(구멍 지름, 간격, 폭, 핀 지름). 이 표가 바뀌면 사용자에게 묻는다.
4. **매개변수(치수표)로 모델링**: 벽 두께·공차·필렛을 변수로. 2D 윤곽(shapely) → 압출/로프트 → 불리언(manifold). 필렛·챔퍼는 마지막에, 가능하면 2D에서.
5. **규칙 검사(QC)** → **조립 검증**(간섭·각도 스윕·간격 분포) → **힘·휨 계산** → **렌더/GIF** → 3MF.
6. **시험편 먼저**: 공차·끼움·경첩 틈은 작은 쿠폰(0.15/0.2/0.25/0.3 mm 변형)을 먼저 뽑고 값을 확정한 뒤 본 모델에 넣는다.

## 2. 형상 규칙 (출력물 기준)
| 항목 | 값 | 비고 |
|---|---|---|
| 오버행 | 층당 바깥 이동 ≤ 0.115 mm(30°), **슬라이서 보정 반영**(코끼리발 0.15, 첫 층 선폭 0.5) | 0.115~0.25/층 "애매한 구간" 설계 금지. 45° 챔퍼(0.2/층)는 바닥 쪽·보이지 않는 곳만 |
| 뒤집어 찍는 윗면 모서리 | 바닥 0.8 mm 수직 띠 → 곡선. 또는 샘플처럼 **45° 챔퍼**(런치박스 뚜껑: 4×4 챔퍼, 0.2/층) | 진짜 필렛은 윗면에 못 쓴다(첫 층부터 급경사) — 보이는 윗면 라운드가 꼭 필요하면 윗면 위로 출력+서포트+아이어닝 |
| 바닥 쪽 모서리(보이지 않음) | 필렛 허용 (샘플 본체: 첫 층 inset 4.9, 0.75/층) — 베드가 받쳐주고 밑면이라 품질 무관 | 단 첫 층 접지 면적은 확보 |
| 벽 | ≥ 1.2(3줄), 상자류는 **3 mm 통일**(샘플) | 뚜껑 스커트 0.95 mm(Toolbox42)는 너무 얇음 |
| 휘는 부재 | ≥ 3 mm, L/t 5~10 | |
| 브리지 | ≤ 5 mm 깨끗, 12~25 mm는 치수 정확도 위해 서포트 없이도 가능(Bambu) | 긴 스팬은 챔퍼/수동 서포트 설계 |
| 수평 구멍 | ≤ 4 mm 서포트 없이, 그 이상 눈물방울 | 핀 구멍 = 핀 + 0.3 |
| 수직 구멍 | +0.3 (작게 나옴) | 정밀은 드릴 |
| 끼움 | 슬라이드 0.2~0.3/한쪽, 압입 0.05~0.15/한쪽, 뚜껑 립 0.1/면(총 0.2)부터 시험 | |
| 첫 층 | 접지 ≥ 첫 층의 70 %·100 mm² 이상, 모서리 챔퍼 0.3~0.5 | 멀티컬러 플레이트는 첫 5층 오버행 0 |
| 작은 부품·삼각형 | <5 mm·<50 mm³ 금지, 파트 ≤ 200k·파일 ≤ 500k | |

## 3. 기구별
- **경첩**: `hinge.md`. 핀 경첩(M3/⌀3 핀): 구멍 3.3~3.4, 너클 벽 ≥ 1.6, 너클 사이 틈 0.3, 핀 축은 베드와 평행하게 눕혀 출력. 프린트인플레이스: 반경 틈 0.2~0.3(작은 너클 0.1~0.15), Z 틈 ≥ 2층(0.4), 핀 아래 챔퍼. PLA는 반복 하중 경첩에 약함.
- **기어**: `gear.md`. 모듈 ≥ 1, 잇수 ≥ 12(17 미만 전위), 압력각 20°, 백래시 0.1 mm, 이뿌리 필렛 0.3·m, 헤링본 나선각 25°, 두께 12~20·m, 눕혀 출력. 하중 기어는 PETG/나일론.
- **스냅핏**: `../snapfit_beam.md`. 변형률 ε=1.5tY/(L²Q) ≤ 4 %(반복), 삽입력 10~30 N 목표, 리드각 30~35°, 리턴각 60~90°. 암은 두께 3·길이 25 mm 급으로 유연하게.
- **나사·인서트**: 인쇄 나사는 M6 이상, 피치 ≥ 0.5, 세워서 출력, 3~4 퍼리미터, 반경 틈 0.1~0.2. **M3는 히트셋 인서트(구멍 4.0~4.2, 보스 외경 ≥ 6.5)** 또는 클리어런스 구멍+탭. 볼트 관통 구멍 3.4.
- **자석**: 포켓 지름 +0.2, 깊이 +0.1, 천장 살 ≥ 0.6(3층), 옆 살 ≥ 0.8 (열쇠고리 프로젝트 값).
- **손잡이·고리**: 사람 손 하중 20 N 기준 처짐 < 0.5 mm, 응력 < 25 MPa(`tools/beam.py`).

## 4. 상자·뚜껑 (샘플에서 배운 틀)
- 본체: 벽 3, 바닥 3, 바닥 모서리 필렛(숨김), 평면 코너 반경 크게(샘플 뚜껑 R≈16).
- 뚜껑: 뒤집어 출력, 윗면 모서리 45° 챔퍼, 스커트 3 mm, 열린 쪽 안에 3 mm 립(채널) — 립 높이 ≤ 뚜껑 안 높이.
- 끼움: 립/채널 0.1~0.2/면부터, 열고 닫으며 길이 드는 것을 감안.
- 경첩·걸쇠는 **본체·뚜껑 밖으로 나온 귀**에 두고(회전 시 벽과 간섭 없게), 핀 축이 벽 바깥에 오게.

## 5. 검증 체크리스트 (보내기 전)
닫힘·조각·삼각형·접지·얇은 살·오버행(출력물 기준)·충돌/간격·회전 스윕·힘/휨/토크·렌더 4뷰+GIF·3MF strict 경고 0.
