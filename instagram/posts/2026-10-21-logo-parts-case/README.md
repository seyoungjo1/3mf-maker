# 나만의 로고 부품케이스

상태: 사용자 요청에 따라 게시 준비 완료. 실물 사진은 각각 한 번 사용한다. 열린 사진은 표지, 닫힌 사진은 작은 글씨를 설명하는 4장으로 이동했다.

## 이야기와 확인된 사실

대진표용 자석 이름표를 정리하고 운반하기 위한 제작. 감상적인 계기 문구는 쓰지 않는다. 이름표 전용 가방으로 명명하지 않는다. 사용자 명칭은 **나만의 로고 부품케이스**다.

- 검은 케이스, 초록 손잡이와 사용자 로고.
- 무늬 있는 빌드 플레이트로 반짝이는 표면을 얻었으나 안착 문제로 작은 글씨가 찌그러졌다. 사용자 설명을 그대로 반영한다.
- M3 × 14mm 나사 6개. 뚜껑 자석 잠금이나 재료·강도·출력 시간은 추정하지 않는다.

## 구성

1. 열린 실물 사진과 닫힌 상태 설계 화면을 배치한 표지. 제목 Jua 104px, 설명 Gamja Flower 49px. 제목 행간 1.18, 설명 행간 1.4로 조정하고 제목 아래 여백과 사진 상단을 맞췄다.
2. 다른 케이스의 AI 스터디와 build123d 설계 코드 요청 과정, 열린 상태 설계 화면.
3. 내부 칸과 이름표 수납 배치 설계 예시.
4. 닫힌 실물 사진 확대, 실제 출력의 작은 글씨 문제와 나사 정보.
5. 느린 설계 애니메이션. GIF를 5배 느리게 하고 시작·끝 2초씩 정지한 24초 MP4.
6. 개인 취미·권리·AI 작성 안내.

실물 사진은 source에 원본을 보존한다. 각 원본 사진은 전체 캐러셀에 딱 한 번씩 사용한다. 생성형 이미지로 제품 형상을 재해석하지 않는다.

## 설계 자료

원본: `작업완료/toolbox48/models/Toolbox48_*_v10.stl`, 조립 상태 정의 `작업완료/toolbox48/scripts/assembly_v10.py`.
원본 STL 좌표를 사용했다. 출력판 배치용 3MF 좌표를 조립 좌표로 사용하지 않는다. 흰 배경의 실제 모델 렌더이며 수납 배치는 설계상 예시다. 잠금 부품의 전체 장착 검증 영상으로 주장하지 않는다.

본문은 [caption.md](caption.md), 업로드 파일은 publish 폴더에 보존한다. 게시 결과는 history에 기록한다.

## AI 제작 과정 표기

사용자 설명에 따라 다른 케이스를 AI로 스터디하고 build123d로 설계 코드를 요청한 과정을 기록했다. 현재 남아 있는 최종 수정 스크립트는 trimesh/shapely를 사용하므로 모든 수정이 build123d만으로 이루어졌다고 단정하지 않는다.
