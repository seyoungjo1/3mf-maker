# 나만의 로고 부품케이스

상태: 최종 구성 수정 중. 실물 사진은 첫 장에만 각각 한 번 사용한다.

## 이야기와 확인된 사실

대진표용 자석 이름표를 정리하고 운반하기 위한 제작. 감상적인 계기 문구는 쓰지 않는다. 이름표 전용 가방으로 명명하지 않는다. 사용자 명칭은 **나만의 로고 부품케이스**다.

- 검은 케이스, 초록 손잡이와 사용자 로고.
- 무늬 있는 빌드 플레이트로 반짝이는 표면을 얻었으나 안착 문제로 작은 글씨가 찌그러졌다. 사용자 설명을 그대로 반영한다.
- M3 × 14mm 나사 6개. 뚜껑 자석 잠금이나 재료·강도·출력 시간은 추정하지 않는다.

## 구성

1. 실물 사진 두 장을 각각 한 번만 쓴 표지. 제목 Jua 104px, 설명 Gamja Flower 49px.
2. 제작 계기와 열린 상태 설계 화면.
3. 내부 칸과 이름표 수납 배치 설계 예시.
4. 닫힌 상태 설계 화면, 실제 출력의 작은 글씨 문제와 나사 정보.
5. 느린 설계 애니메이션. GIF를 5배 느리게 하고 시작·끝 2초씩 정지한 24초 MP4.
6. 개인 취미·권리·AI 작성 안내.

실물 사진은 source에 원본을 보존한다. 이후 장에는 실물 사진을 반복하지 않는다. 생성형 이미지로 제품 형상을 재해석하지 않는다.

## 설계 자료

원본: `작업완료/toolbox48/models/Toolbox48_*_v10.stl`, 조립 상태 정의 `작업완료/toolbox48/scripts/assembly_v10.py`.
원본 STL 좌표를 사용했다. 출력판 배치용 3MF 좌표를 조립 좌표로 사용하지 않는다. 흰 배경의 실제 모델 렌더이며 수납 배치는 설계상 예시다. 잠금 부품의 전체 장착 검증 영상으로 주장하지 않는다.
